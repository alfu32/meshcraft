# T71 — Home screen

Status: **Complete**, 0.49.0 · U06/O01 · C44.

## Delivered

- A plain launch opens on Home. The title-bar button, `file.home` and Esc toggle it.
- Five unit presets through `file.new` `preset`: `urban_planning`, `architecture_metric`,
  `architecture_imperial`, `product_metric`, `product_imperial`. They use the existing
  presentation-only `unit_name`/`unit_size` settings and do not rescale geometry.
- Open, and Import through `import.mesh` `new_document`, which prompts for unsaved edits.
- Recent with path, age, missing-file state and a preview written beside the preferences.
- Nine samples embedded from `assets/samples/` (about 6 MB of the executable) through
  `file.open_sample`. They load on the project worker and never bind to a path.

## Behavior changes outside the screen

- Save As to a new location now joins Recent. Only opening did before.
- Replacing the document now frames the new content (`sync_document_camera`). Previously the
  shell kept its camera after File > Open, so a project could open as a close-up at the origin.
  Samples restore their authored camera. Other projects are fitted, because the shell's orbit
  camera is not written back to the session camera that gets saved.

## Validation

Evidence: [references/home-screen](../references/home-screen/), including `native-validation.json`.
`python3 scripts/verify_home_screen.py` uses real pointer and key events in a private Xvfb display.

**Not exercised:** the native file dialogs behind the Open, Import, Save As and Export actions,
because Xvfb has no desktop portal. Those paths were exercised with explicit `path` arguments.
Only Linux under software Vulkan was run locally; Windows and macOS depend on the release builds.
