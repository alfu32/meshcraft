## Known limits

- One Stretch handle moves everything attached by the same offset, so it sizes one direction. Width and height need
  a handle each.
- A marker at k steps gives k+1 panels, except at its carried position, which gives one. So two panels need a marker
  past one step rather than exactly on it.
- With two hotspots selected, Attach goes to the older one, whatever the selection order. A user cannot attach an
  older handle to a newer one this way, and the tutorial places the driving handle first.
- Widening after multiplying moves the marker by the widening only, so the panel count can drop.
- Drawing a window needs a surface, so the tutorial draws a holding wall and deletes it.
