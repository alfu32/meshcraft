# T61 — Material catalog and initial color rendering

Status: **Complete** · Requirements P07 · Acceptance C42 · Version 0.6.0.

The document owns a default material and stable named material records with RGBA,
shading type, optional texture path and positive U/V model-unit sizes. Newly
constructed faces bind the Default material. Imports remap colliding catalog IDs.
Legacy direct painting is promoted to a material binding; catalog edits update bound fallback colors.
Assignment follows selection visibility/editability and prototype edit scope.

The GPUI Materials panel shows swatches/names and New Material, Edit and Apply to
Selection controls. The modal editor supports Save/Cancel and validates input.
Creation, edits and assignments use ordinary document undo. The initial renderer
uses RGBA; texture sampling and per-material lighting algorithms remain deferred.

## Material controls and color picker — 0.27.0

Native model painting opens the material catalog, and wall/slab/frame surface
controls select material IDs. Architecture keeps those references when rebuilt;
editing materials refreshes canonical fallback colors, with collision remapping on
import. Legacy unbound geometry is migrated in a bulk pass. Hotspots remain RGBA.
The vendored color picker now defaults to HSL and offers RGB and Swatches, each
with an opacity bar. HSL/RGB have smooth draggable planes, numeric channels and
RGBA hex. Swatch changes preserve opacity. Native edits saved the exact expected
RGBA values; see [release validation](object-properties-validation.md).

## Drawing palette and unused-material deletion — 0.30.0

New drawings seed the 16 ANSI slots using conventional VGA RGB values, with
stable lowercase names/IDs (`ansi-black`, `ansi-grey`, `ansi-bright-red`, etc.).
Normal white/grey is #c0c0c0, dark-grey #808080 and bright white #ffffff.
Architecture adds smoke-white (#ededed), smoke-grey (#d6d6d6), side-grey (#e0e0e0)
and glass (#b8d6f266). Creation defaults bind lines to ansi-black and faces to
ansi-grey; architecture defaults use the named surface materials. Scripted
segments/faces also default to black/grey; explicit catalog materials retain
metadata and references in evaluated output.

Older catalogs receive the palette once without changing authored RGBA values or
legacy white `default` references. A persisted palette-version marker distinguishes
migration from deliberate deletions, so deleted unused colors remain deleted after
save/reopen. A bounded, left-aligned scrolling list keeps manager actions visible.
Delete is undoable and exposed as `material.delete` through the command/MCP catalog.
It rejects references in authored/unplaced prototypes, occurrence replacements,
nested default edits, evaluated script geometry, architecture owners and creation
defaults. The six implicit line/face/architecture defaults remain available even
in an empty drawing. Other unused ANSI colors and custom materials can be deleted.
