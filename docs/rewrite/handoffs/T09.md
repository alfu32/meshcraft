# T09 handoff

Status: in progress. Open, Save, and Save As share the desktop command registry; autosave and recovery remain open.

`File > Open Project…` and `Ctrl+O` use a cancellable worker reader with progress, 512 MiB encoded/decoded limits, candidate validation, and revision-guarded publication. `File > Save`/`Ctrl+S` and Save As/`Ctrl+Shift+S` serialize an immutable document snapshot on a worker. Typed command payloads accept `path`; otherwise native dialogs choose files. JSON/gzip output uses schema 17 and the 10 MiB threshold. A same-directory temporary file is synced and renamed into place. Successful completion records the revision written, so edits made during the save remain dirty. Failed writes leave the active document and saved path unchanged.

Dirty documents block Open and New until saved. Clean saves retain imported opaque undo history. Dirty saves omit history snapshots that no longer describe the saved model and report this in status; persisting edited Rust history in the legacy format remains open. Browser file storage, autosave debounce, recovery backups, and Kotlin reopen checks are not implemented.

Checks: `cargo test --workspace` passes (68 core, 40 desktop, 12 IO), including Save/Save As success and failed-write state handling. Native dialogs were not manually exercised.

Changed paths: `apps/desktop/src/app.rs`, `crates/meshcraft-core/src/{document.rs,legacy.rs}`, and `crates/meshcraft-io/src/project.rs`.

Keep T09 in progress until autosave/recovery and C03/C05/C17 acceptance pass.
