# T09 handoff

Status: in progress. The native Open Project slice is implemented; Save, Save As, autosave, and recovery are still open.

`File > Open Project…` and `Ctrl+O` share the desktop command registry and native file picker. Typed `file.open` dispatch accepts an optional `path` for automation. File reads stream in cancellable chunks on a worker thread, project decoding reports progress and observes cancellation, and the 512 MiB encoded/decoded limits are enforced. The reader stages and validates an `ImportedProject`; the UI installs it only when the document revision still matches the revision captured at load start. Failure, cancellation, or a stale revision keeps the active document intact. Successful install resets native undo, selection, tool drafts, and camera state while preserving imported legacy history.

Save and Save As remain disabled because the Rust document still has no schema-17 project serializer. `encode_project_json` only handles the legacy byte-container compression rule; using it with Rust document JSON would create an incompatible `.octd`. Edited documents therefore block Open until saving is implemented. Startup CLI loading remains available.

Checks: `cargo test -p meshcraft-desktop --lib`; `cargo check -p meshcraft-desktop --lib`; `cargo check -p meshcraft-desktop --lib --target wasm32-unknown-unknown`.

Remaining: implement schema-17 serialization, immutable-revision saves, temporary-file/atomic replacement and recovery, autosave debounce, save naming/dialog flows, and the Kotlin reopen/failure acceptance checks. C03, C05, and C06 remain release gates; no native dialog was manually exercised in this handoff.
