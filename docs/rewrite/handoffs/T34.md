# T34 — External object scenes (in progress)

Implemented 2026-10-20: `Document::import_subscene` imports a complete scene as a prototype without flattening its hierarchy. Geometry and layout identities are remapped, root hotspots retained, and nested instance values become child-layout defaults. Optional external path metadata distinguishes references from internal snapshots. Refresh preserves prototype identity and instance values; failed reads/imports retain cached geometry. Removed source children discard only their now-unresolvable descendant overrides; refresh rebinds surviving paths by source alias/name.

`object.import_scene`, `object.reference_scene` and `object.refresh_reference` load/decode files on a worker, commit on the session thread and expose job completion. Import jobs cannot publish into a replaced document. The Objects browser exposes all three actions.

The schema-17-compatible `meshcraftChildren` extension preserves unused prototype subscenes; legacy readers can ignore it. The normalized child layout stores default instance edits, while explicit occurrence edits remain independent. Nested values and root handles survive actual project save/reopen.
