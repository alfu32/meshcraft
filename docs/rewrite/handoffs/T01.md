# T01 handoff

Status: complete. Locked Rust 1.99.1/MSRV 1.95 and eframe 0.37 with Wgpu, X11 and Wayland support. The native workspace requests maximized startup; EWMH reported a maximized 1882×1011 client on the 1920×1080 display.

- Native proof: the egui menu bar renders; `Ctrl+Shift+P` opens the palette and Enter dispatches registered commands. The X11 smoke test created a cuboid, copied it, grouped it as an object, and arrayed it through palette search. Line and Rectangle buttons create selectable geometry with live previews; Escape cancels an unfinished tool. An app-level egui test verifies palette focus, regular text search, IME preedit, and IME commit. This tests the egui input path, not an OS input-method daemon.
- Menu decision: use the in-window egui menu on desktop and share it with the other profiles. It was exercised on X11; do not claim OS-native menu-bar behavior. ADR-04 defers any native adapter until T08, where it can use the shared command tree if platform testing shows a benefit.
- Viewport mapping: projection and ground-pick round trips pass with a nonzero viewport origin and multiple camera orbits.
- Geometry proof: `experiments/stack` records concave union, holes, overlap, self-intersection, near-collinear polygonization and triangulation cases.
- Asset proof: the pinned 32/48/64-pixel legacy tool-icon atlases and coordinate map are preserved under `assets/tool-icons/` with the source license. The shell loads the 32-pixel PNG and displays Select, Line, Rectangle and Orbit icons in buttons and palette results; atlas bounds are tested.
- Visual checks: maximized 1882×1011 native shell, 15-command palette, and cuboid/line/rectangle workflow are captured in `docs/rewrite/references/meshcraft-tool-icon-shell.png`, `docs/rewrite/references/meshcraft-icon-command-palette.png`, and `docs/rewrite/references/meshcraft-line-rectangle-workflow.png`.
- WASM proof: desktop library and geometry spike compile for `wasm32-unknown-unknown`; browser product integration remains deferred.
- ADRs 04/05/09 record UI, precision and polygon-kernel choices.

Checks on 2026-10-18: `cargo fmt --all --check`; `cargo test --workspace` (40 tests passed); `cargo clippy --workspace --all-targets -- -D warnings`; `cargo check -p meshcraft-desktop --lib --target wasm32-unknown-unknown`; `python3 docs/rewrite/scripts/verify_plan.py` all passed. A maximized native X11 smoke test confirmed Line, Rectangle, cuboid creation, the copy/object/array palette workflow, `Ctrl+Shift+P` palette opening, and F10 menu opening.

The native input-method daemon and OS-native menu adapters are not qualified here; these remain platform/release checks under C23/C31. Browser product integration remains T45.
