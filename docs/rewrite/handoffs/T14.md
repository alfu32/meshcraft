# T14 handoff

Status: complete. Rectangle, Surface Rect, Quad and Circle are active point-picking tools with viewport previews and measurement labels. Their commands are available through the command palette and Tools menu.

Rectangle and Surface Rect use two picks; Surface Rect keeps the first face normal and projects the second pick onto that plane. Quad uses three picks and constructs its fourth corner as `B + (C - A)`. Circle uses the model's configured segment count, defaults to 24 and retains the legacy fan winding. Each tool validates degenerate input and clears pending picks on cancel.

Shapes append edges and triangles to the active scene-root or entered definition graph in local space. Boundary edges use the same split and collinear-overlap path as Line. New faces do not implicitly cut existing faces. Commits select the created/reused edges and new triangles as one undoable operation; repeated shape picks keep the tool active.

Checks: `cargo test --workspace --quiet` passes (101 core, 118 desktop, 14 IO, 5 CLI); `cargo clippy --workspace --all-targets -- -D warnings`, formatting and `verify_plan.py` pass. Coverage includes ground and tilted-plane rectangles, reversed picks, parallelogram geometry, non-default circle resolution, rotated instance editing, edge splitting, preview measurements, cancel and undo.

Changed paths: core shape tools and document geometry, desktop app and viewport, `docs/rewrite/tasks.json`, `DASHBOARD.md` and this handoff.

Next: T15 transforms, stretch variants and painting.

## Circle insertion latency correction — 2026-10-20

Isolated planar outlines now append in one batch; touching/intersecting outlines retain ordinary line topology. Line insertion rebuilds only touched segments, preserving unrelated junctions, IDs and raw references. See the [interaction/performance validation](interaction-performance-validation.md) for regression coverage and measured circle commit latency.
