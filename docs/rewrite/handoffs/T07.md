# T07 handoff

Status: in progress. T01, T03, and T06 are complete; this records the delivered shell/viewport slices without claiming T07's completion conditions.

The desktop viewport now uses right drag for perspective orbit, Shift+right drag for pan, and middle drag for pan. Orbit updates yaw and elevation; projection, face-facing/depth sorting, picking, and height input use the same elevation-aware camera basis. Wheel zoom preserves the ground point under the pointer. Camera input starts only when the viewport is the topmost egui layer and remains captured until button release. Viewport mapping tests cover panel/menu offsets, multiple sizes, all orthographic construction planes, and native DPI scales of 1, 1.5, and 2 using egui's logical-point coordinates.

The native executable accepts one positional project path or `--open <path>`, `--size WIDTHxHEIGHT`, `--windowed`, `--maximized`, `--help`, and `--version`. It starts maximized by default; an explicit size selects windowed mode. Size parsing rejects malformed/conflicting values and respects the app's 900×600 minimum. No arguments open the valid empty document.

Changed paths: `apps/desktop/src/{main.rs,viewport.rs}`. Remaining: native resize/close and device-loss validation; renderer readback and transformed-fixture visuals; complete focus/capture routing and C09/C10/C24 acceptance. Camera persistence, orthographic projection, and walkthrough behavior are implemented under T10 and remain subject to broader acceptance coverage.
