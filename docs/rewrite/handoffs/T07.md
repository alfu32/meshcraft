# T07 handoff

Status: in progress. T01 and T03 are complete; T06 remains in progress, so this records implemented shell/viewport slices without satisfying T07's completion conditions.

The desktop viewport now uses right drag for perspective orbit, Shift+right drag for pan, and middle drag for pan. Orbit updates yaw and elevation; projection, face-facing/depth sorting, picking, and height input use the same elevation-aware camera basis. Wheel zoom preserves the ground point under the pointer. Camera input starts only when the viewport is the topmost egui layer and remains captured until button release.

The native executable accepts one positional project path or `--open <path>`, `--size WIDTHxHEIGHT`, `--windowed`, `--maximized`, `--help`, and `--version`. It starts maximized by default; an explicit size selects windowed mode. Size parsing rejects malformed/conflicting values and respects the app's 900×600 minimum. No arguments open the valid empty document.
