# T73 — Title bar command search and Home ribbon cleanup

Status: **Complete**, 0.51.0 · U08 · C46. Request: `tasks/todo/UI-redesign-2/task.md`.

## Delivered

- A right-aligned search box, search button and chevron on the title bar replace the Commands button.
- The menu bar is hidden by default. A saved "Show menu bar" setting is kept, so existing profiles
  keep their menu bar until UI Settings turns it off.
- Home holds Selection, Draw, Annotations, Transform, Guides and its two pickers.

## Validation

Evidence: [references/title-bar](../references/title-bar/), including `native-validation.json`.
`python3 scripts/verify_title_bar.py` uses real pointer and key events in a private Xvfb display,
including a launch with a fresh profile. `verify_functional_ui.py`, `verify_workspace_controls.py`
and `verify_home_screen.py` keep the menu bar on through their own preferences, because their pointer
coordinates assume it. The release gate passes.

**Not exercised:** dragging the window beside the search box (no window manager under Xvfb), Windows
and macOS title bars, and the full stress suite.
