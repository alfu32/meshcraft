# T52 handoff

Status: complete. Resolves [GitHub bug #3](https://github.com/alfu32/meshcraft/issues/3).

Scope: reduce the flat Tools menu while keeping frequent commands easy to reach.

Completed: command presentation now supports additive menu aliases. Built-in tools receive primary menu paths from `LEGACY_TOOLBAR_TOOL_IDS` and the source toolbar labels; unassigned commands are grouped under Other Tools. The Tools menu renders these paths as submenus. Select, Line, Rectangle, Circle, Push/Pull, Move, Copy Selection, Rotate and Stretch remain directly available at the root. Menu entries continue through the shared command registry, preserve capability-aware disabled state, and remain discoverable in the palette. Older serialized command presentations deserialize with empty aliases.
