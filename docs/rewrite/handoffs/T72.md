# T72 — Title bar commands and recomposed ribbon

Status: **Complete**, 0.50.0 · U07 · C45. Request: `tasks/todo/UI-redesign/task.md`.

## Delivered

- 21 title bar buttons for Files, Import & Export and Clipboard & History, removed from the
  ribbon, left panel and dropdown menus. Disabled while a modal is open; hidden on Home.
- Seven ribbon tabs: Home, Construction, Solids, Civil, Materials, Objects & Hotspots, Settings.
- Recent Files now opens a real list. `file.open_recent` previously set a dialog flag that
  only the web shell draws, so the native ribbon button had no visible effect.

## Validation

E## Validation

Evidence: [references/title-bar](../references/title-bar/), including `native-validation.json`.
`python3 scripts/verify_title_bar.py` uses real pointer events in a private Xvfb display. It also
caught and now guards one defect: a long path at minimum width pushed the window controls off-screen.
`verify_functional_ui.py`, `verify_workspace_controls.py` and `verify_home_screen.py` pass, and the
user tested the build by hand. Release gate: `cargo fmt --all --check`,
`cargo test --workspace --locked` and
`cargo clippy --workspace --all-targets --locked -- -D warnings` pass.

Screenshots were recaptured with `capture_store_projects.py --capture-only`. That run also rewrote
three project files with float rounding and an undo timestamp, which would have made their embedded
samples stale, so those three files were restored.

**Not exercised:** dragging the window beside the buttons (no window manager under Xvfb), Windows
and macOS title bars, and native file dialogs. A local small-tier stress run was stopped by its time
limit at 63 of 295 cases, so it does not establish coverage.
