# T33 — Instance hotspot operations (in progress)

Implemented 2026-10-20: all eight k3d hotspot operators, five marker shapes and RGBA colors. Bindings retain stable edge/face/vertex identities, with legacy coordinate-key reconciliation. Attachment graphs reject cycles. Runtime geometry and resolved positions are derived from prototype content and absolute occurrence targets; caches are excluded from serialization/history. Copies preserve targets and subsequent drags remain independent. Split/deleted geometry reconciles bindings at the topology boundary.

GPUI renders screen-sized handles over the offscreen scene. Dragging a closed instance previews geometry and relative measurements, commits once, and cancels on Escape. Prototype editing authors shared properties/bindings and uses an authored view; runtime deformation is preserved outside that view. Nested child copy/move/delete edits the shared subscene. Nested instance handle defaults are distinct from outer-instance runtime overrides.

Checks at the implementation checkpoint: `cargo test -p meshcraft-core -p meshcraft-io -p meshcraft-desktop --lib --offline` — 224 core, 237 desktop, 15 IO passed; one GPU test ignored. Cases cover independent values, copy, undo, cache invalidation when entering/exiting editing, sparse legacy corner identities, operator DTO names, topology splitting, nested shared layouts, and external save/reopen. Initial live GPUI checks observed handle deformation, prototype wireframe insertion and faded isolated editing. Final live UI checks and wider C15/C16/performance/platform qualification remain outstanding.
