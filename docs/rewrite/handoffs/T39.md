# T39 handoff

Status: in progress. T17 provides the existing model settings panel; C24 owns renderer and capture evidence.

Active slice: reproduce the legacy face orientation tint (back faces darker and slightly bluer) and add a shadow-map pass that shades entity receivers and projects casters onto the ground plane. The current renderer is an egui painter, so the first implementation will use a bounded CPU depth map and preserve painter-based selection/guide overlays. Issue [#12](https://github.com/alfu32/meshcraft/issues/12) exposed inconsistent tint across a triangulated planar face; orientation propagation now also recognizes adjacent triangles whose shared edge has coincident positions but distinct vertex IDs.

Requirements: front/back face color difference; entity shadows on the ground and other entities; stable behavior for transformed occurrences. Keep selection highlights legible and avoid treating the face itself as an occluder.

Remaining T39 scope: persist and convert directional/ambient/specular/shadow controls, filtering and quality settings, and inclusion-aware GPU PNG/SVG capture with completion notifications. Validate acne/bias, varying scale, transparency, and fixed-camera readback under C24.

Implementation: the painter pipeline builds a 192×192 light-space depth map from visible scene triangles, including transformed scene occurrences. Entity triangles use a 3×3 PCF-style depth comparison with scale-relative bias; the ground receiver samples the same map on a 96×96 world grid beneath the viewport grid. Face orientation tint preserves alpha. Selection overlays remain legible. This is a CPU shadow-map baseline; it does not yet expose legacy shadow controls or per-object casting toggles.

Checks: `cargo test --workspace --quiet` passes (214 core, 204 desktop library, 15 IO and 5 CLI tests). The duplicate-position regression passes, as do the shared-vertex winding, back-face tint and shadow-map tests. `cargo clippy --workspace --all-targets -- -D warnings`, `cargo fmt --all -- --check`, `git diff --check` and `python3 docs/rewrite/scripts/verify_plan.py` pass. Tests cover darker/bluer back faces, transparency preservation, ground occlusion, a caster shadowing a separate entity face, out-of-map receivers, self-shadow bias, and uniform orientation propagation across planar triangulation.
