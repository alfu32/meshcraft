Status: in progress. T13 implements the Line and Construction Line slice; generic copy/operator dispatch and the hotspot-operation hook remain unresolved, so the task is not marked complete.

Progress: core exposes `DrawingTool`, `ToolEvent`, `ToolEffect`, `ToolPreview`, `DrawingToolState`, and `operations::drawing::insert_line`. An explicit scene-root definition stores direct root entities. Line insertion targets the root or active definition in local space, splits same-graph intersections and endpoint-on-edge contacts, and merges collinear overlaps without cutting faces. Selection remaps update inherited instances. Pointer/world-pointer input, numeric preview/commit, and Enter/Backspace/Escape share the state path. The in-tool toolbar exposes Select and state-gated Distance; Finish, Undo Point/Input, and Cancel are palette commands.

Transaction policy: each committed segment is independently undoable. Line advances its anchor and stays active; Enter finishes its chain without switching tools. Construction Line resets after each pair and stays active. Escape discards pending input while retaining committed geometry.
