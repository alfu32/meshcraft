Move, Rotate, Scale, Stretch, Stretch Scale and Rotate Stretch use a shared point-picking state with numeric input, axis constraints, copy mode where characterized, cancel/backspace and immutable source-based previews. Transform commits update shared vertices once, preserve per-corner offsets, validate atomically and create one undo entry. Nested object-occurrence copies are now supported through parent-layout isolation and path remapping, including repeated arrays; see the T16 and T21 handoffs. Semantic/domain, voxel and hotspot transform adapters remain with T28/T32/T33, and typed annotation transforms belong to T18. ## Fragment transforms and explicit copy buttons — 2026-10-20

Ordinary Move/Rotate/Scale detach selected edge/face boundaries from unselected geometry, including extruded meshes. Explicit selected vertices and Stretch variants retain connected behavior. Dedicated `tool.move_copy` and `tool.rotate_copy` commands enable copy mode and accept raw mesh fragments; their tests verify new IDs, unchanged source geometry and undo. Previews follow the same detached/connected distinction. See [validation](interaction-performance-validation.md).

## Squash and center-relative rotational feedback — 0.23.0 (2026-10-22)

`tool.squash` is available in Modify, the ribbon/left panel, command discovery and
MCP. Its bold icon is generated with the existing slate. Select supported geometry,
pick center, an axis reference and a target distance, or enter a signed scale factor.
The affine transform scales only the component along the picked axis; perpendicular
components and the center are preserved. Negative factors reflect; collapsed
references and zero/nonfinite factors reject atomically. The regular selected-fragment
transform, preview, cancel and undo path applies. This does not add a legacy ToolId.

Rotation, Rotate 2 and Rotate Stretch retain center-to-reference rays and point
markers through input, report pairwise vector angles and the projected applied
rotation, and draw its arc when defined. Four-point rotation distinguishes its
axis from the two angle references. Measurements use the first center rather than
the preceding pick. Rotational arrays and revolve also keep center-relative rays
and vector-pair feedback.

Validation: the **605-test** workspace run, strict Clippy and desktop build pass;
see the [shared commands and results](T29.md#owner-only-drag-wireframes-and-free-controls--0230-2026-10-22).
Core regressions cover an oblique axis, negative factor, zero rejection, preserved
perpendicular components and center, retained rotation rays, pairwise angles and
projected angle. Desktop regressions cover command activation, axis-only Squash,
one-step Undo/Redo and every rotation pick stage. In isolated GPUI/Xvfb,
`python3 target/ci-debug/native-finish/transforms_native.py` verified Squash's
0.5/1/1 axis scales, Undo/Redo, and visible three-ray rotation preview with a
−90° applied angle and three 90° vector-pair labels; Escape retained the original
transform. [Assertions](../references/interaction-controls/validation.json),

## Buffered entry and copy counts — 0.29.0

Point workflows share an append/backspace buffer for internal/physical lengths
and relative coordinates. Transform angles/factors retain their stage-specific
meaning. xN and /N commit source-based arrays atomically, including Scale/Squash
Copy Mode. Division preserves the original signed angle and interpolates scale
from identity; repeated scale transforms compound. UI and MCP use the same paths.
See the [guide](../../numeric-tool-input.md) and
