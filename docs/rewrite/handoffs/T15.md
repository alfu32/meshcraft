# T15 handoff

Status: complete for raw mesh geometry and object occurrences. Move, Rotate, Scale, Stretch, Stretch Scale and Rotate Stretch use a shared point-picking state with numeric input, axis constraints, copy mode where characterized, cancel/backspace and immutable source-based previews. Transform commits update shared vertices once, preserve per-corner offsets, validate atomically and create one undo entry. Object occurrences can be transformed independently; mixed selected edges/faces copy their topology and payloads, and the copied result becomes the selection.

The desktop command surface exposes the transform tools, `tool.copy_mode`, `tool.distance`, `tool.finish` and `tool.undo_point`. Orange wire previews derive from the original selection. Paint supports selected or clicked edges/faces, a current RGBA picker, `paint.set_color` and `paint.apply_selection`; unchanged colors do not add history entries.

Semantic/domain, voxel and hotspot transform adapters remain with T28/T32/T33. Typed annotation transforms belong to T18. Copying a nested object occurrence is not supported yet and remains with T16. These selections return a clear unsupported-selection error without changing the document.

Checks: `cargo test --workspace` passes (112 core, 123 desktop, 14 IO, 5 CLI); `cargo clippy --workspace --all-targets -- -D warnings`, `cargo fmt --all -- --check`, `git diff --check` and `python3 docs/rewrite/scripts/verify_plan.py` pass. Tests cover face movement, instance isolation, mixed topology copy, four-point rotation, constrained scale, numeric viewport input, click paint, RGBA command flow, preview stability and unsupported semantic targets.
