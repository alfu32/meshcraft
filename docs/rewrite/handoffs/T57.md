# T57 — Bevy renderer and UI migration

Status: **In progress**. This is the high-priority native migration for [issue #19](https://github.com/alfu32/meshcraft/issues/19), linked to the performance report in [issue #18](https://github.com/alfu32/meshcraft/issues/18).

## Implemented vertical slice

- Pinned Bevy 0.20.0 for the native desktop target and raised the workspace MSRV to Rust 1.97.1. The core and IO crates remain Bevy-free.
- Switched the native binary entry point to Bevy while retaining the existing eframe adapter for WASM during migration. The Bevy app now hosts the existing `MeshcraftApp` document/session and command dispatcher as its native session bridge, preserving imported legacy history and the startup project path for Save.
- Loaded projects into the authoritative `Document` and resolved root geometry, nested object instances and per-occurrence geometry into scene-wide GPU batches: front faces, back faces, authored edges and grid, plus a ground mesh. This follows K3D's single `ModelBatch` scene pass and `ShapeRenderer` line pass while combining resolved geometry more aggressively.
- Added front/back face batches with a darker, bluer back-face tint. Solid front faces cast shadow-map shadows; modeled lines, grid, duplicate back faces and the ground do not enter the shadow pass. The ground still receives shadows. Separate direct and fill lights soften contrast.
- Seeded live lighting controls from K3D's visible defaults: shadow `0.59`, directional `0.73`, ambient `0.59`, specular `0.20`, bias `2500` / `5620`, and cascaded shadows enabled. The Bevy UI exposes ambient/direct/specular sliders plus native shadow-filter and cascade controls. Bevy's physical ambient scale and filtering modes are approximate translations, not shader-uniform parity.
- Expanded the Bevy UI shell with grouped tool buttons, a scrollable inspector containing the reference panel sections, and a searchable command palette (`Ctrl+Shift+P`) populated from the shared command registry. Palette entries and tool buttons dispatch their existing command IDs through `MeshcraftApp`; keyboard text, Backspace, arrow selection, Enter and Escape work in the palette.
- Scene face/edge batches now refresh when the session document generation or revision changes. Pointer and idle frames do not rebuild unchanged meshes; replacing a loaded project with a matching revision still invalidates the scene through its generation counter.
- Right-drag orbits the camera; the wheel zooms. Camera pitch is clamped to ±89°.
- Added tests for palette registry search, native session command dispatch and resulting render-source geometry, plus mesh conversion, bounds, counts, empty batches, lighting defaults and back-face tint.

## Remaining acceptance work

- Extract UI-independent command/session ownership from the remaining egui-shaped `MeshcraftApp` bridge, and route viewport point input into its staged tool state so tools operate on selected entities and picked points.
- Complete the searchable palette's parameter entry and enabled-state presentation; port floating/dockable toolbars, right-click context menu and interactive inspector/settings controls.
- Add GPU picking and spatial queries without full-scene work on pointer movement; port snapping, cursor/guides, selection picking and left-to-right/right-to-left selector windows.
- Reproduce a pinned scene with at least 2,000 entities and record hardware, GPU, build profile, frame time, hover/pick latency and a representative edit against the T00 baseline.
- Carry forward and visually validate the toolbar, cursor, guide, selection and rendering work tracked by issues #8–17 before closing those issues.
- Recheck native package behavior and the independent WASM adapter after the desktop UI migration.

## Validation

`cargo test --workspace --quiet` passes (214 core, 219 desktop, 15 IO and 5 CLI tests); `cargo clippy --workspace --all-targets -- -D warnings`, `cargo check -p meshcraft-desktop --lib --target wasm32-unknown-unknown`, formatting and plan verification pass. The focused Bevy suite covers registry search, palette refresh scheduling, actual toolbar/palette activation events through shared dispatch, native document mutation and rendered-document mesh output. The native app starts on the NVIDIA Vulkan adapter. The 2,000-entity frame/hover/pick/edit measurements remain required before T57 can be completed; do not report an improvement over issue #18 until they are recorded.
