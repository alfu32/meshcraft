# T57 — Bevy renderer and UI migration

Status: **In progress**. This is the high-priority native migration for [issue #19](https://github.com/alfu32/meshcraft/issues/19), linked to the performance report in [issue #18](https://github.com/alfu32/meshcraft/issues/18).

## Implemented vertical slice

- Pinned Bevy 0.20.0 for the native desktop target and raised the workspace MSRV to Rust 1.97.1. The core and IO crates remain Bevy-free.
- Switched the native binary entry point to Bevy while retaining the existing eframe adapter for WASM during migration.
- Loaded projects into the authoritative `Document` and resolved root geometry, nested object instances and per-occurrence geometry into scene-wide GPU batches: front faces, back faces, authored edges and grid, plus a ground mesh. This follows K3D's single `ModelBatch` scene pass and `ShapeRenderer` line pass while combining resolved geometry more aggressively.
- Added front/back face batches with a darker, bluer back-face tint. Solid front faces cast shadow-map shadows; modeled lines, grid, duplicate back faces and the ground do not enter the shadow pass. The ground still receives shadows. Separate direct and fill lights soften contrast.
- Seeded live lighting controls from K3D's visible defaults: shadow `0.59`, directional `0.73`, ambient `0.59`, specular `0.20`, bias `2500` / `5620`, and cascaded shadows enabled. The Bevy UI exposes ambient/direct/specular sliders plus native shadow-filter and cascade controls. Bevy's physical ambient scale and filtering modes are approximate translations, not shader-uniform parity.
- Expanded the Bevy UI shell with grouped tool buttons, a scrollable inspector containing the reference panel sections, and a clickable/keyboard command palette (`Ctrl+Shift+P`). Right-drag orbits the camera; the wheel zooms. Camera pitch is clamped to ±89°. Tool buttons currently select a displayed tool; shared command/session dispatch is still open.
- Added mesh-conversion tests for face, edge and grid output, bounds, counts, empty batches and back-face tint.

## Remaining acceptance work

- Port command dispatch and session ownership so UI actions invoke shared services and all model tools operate on selection as specified.
- Port the full command palette, floating toolbars, context menu, inspectors/settings, snapping, cursor/guides, selection picking and both-direction selector window.
- Replace the startup-only mesh build with revision-based mesh caching and update invalidation; add GPU picking and spatial queries without full-scene work on pointer movement.
- Reproduce a pinned scene with at least 2,000 entities and record hardware, GPU, build profile, frame time, hover/pick latency and a representative edit against the T00 baseline.
- Carry forward and visually validate the toolbar, cursor, guide, selection and rendering work tracked by issues #8–17 before closing those issues.
- Recheck native package behavior and the independent WASM adapter after the desktop UI migration.

## Validation

Run `cargo check -p meshcraft-desktop --bin meshcraft` for the native shell and `cargo test -p meshcraft-desktop --lib bevy_app::tests` for scene conversion and lighting defaults. Full workspace, WASM and performance checks remain required before T57 can be completed. Do not report an improvement over issue #18 until the 2,000-entity measurement is recorded.
