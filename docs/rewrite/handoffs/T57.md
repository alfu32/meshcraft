# T57 — Bevy renderer and UI migration

Status: **In progress**. This is the high-priority native migration for [issue #19](https://github.com/alfu32/meshcraft/issues/19), linked to the performance report in [issue #18](https://github.com/alfu32/meshcraft/issues/18).

## Implemented vertical slice

- Pinned Bevy 0.20.0 for the native desktop target and raised the workspace MSRV to Rust 1.97.1. The core and IO crates remain Bevy-free.
- Switched the native binary entry point to Bevy while retaining the existing eframe adapter for WASM during migration. The Bevy app now hosts the existing `MeshcraftApp` document/session and command dispatcher as its native session bridge, preserving imported legacy history and the startup project path for Save.
- Loaded projects into the authoritative `Document` and resolved root geometry, nested object instances and per-occurrence geometry into scene-wide GPU batches: front faces, back faces, authored edges and grid, plus a ground mesh. This follows K3D's single `ModelBatch` scene pass and `ShapeRenderer` line pass while combining resolved geometry more aggressively.
- Added front/back face batches with a darker, bluer back-face tint. Only solid front faces cast shadow-map shadows; authored lines, selection overlays, grid, duplicate back faces and ground stay out of the shadow pass. The ground still receives shadows. Separate direct and fill lights soften contrast.
- Seeded live lighting controls from K3D's visible defaults: shadow `0.59`, directional `0.73`, ambient `0.59`, specular `0.20`, bias `2500` / `5620`, and cascaded shadows enabled. The Bevy UI exposes ambient/direct/specular sliders plus native shadow-filter and cascade controls. Bevy's physical ambient scale and filtering modes are approximate translations, not shader-uniform parity.
- Expanded the Bevy UI shell with all 13 legacy toolbar groups, built from the shared toolbar/command catalog, plus a scrollable inspector containing the reference panel sections and a searchable command palette (`Ctrl+Shift+P`). Toolbar buttons reuse the embedded 32×32 legacy icon atlas, dispatch command IDs through `MeshcraftApp`, gray out unavailable commands, and highlight the active tool. Palette entries reuse shared enabled/checked state, display disabled reasons, and cannot dispatch while unavailable; rejected Enter commands leave the palette open. Keyboard text, Backspace, arrow selection, Enter and Escape work in the palette.
- Parameterized palette commands open a schema-guided JSON object editor. Keyboard editing supports character insertion/deletion and cursor movement; Enter validates and dispatches through the shared command registry, while invalid JSON, wrong value types and command rejection stay visible for correction.
- Scene face/edge batches now refresh when the session document generation or revision changes. Pointer and idle frames do not rebuild unchanged meshes; replacing a loaded project with a matching revision still invalidates the scene through its generation counter.
- Routed native viewport pointer input through Bevy camera rays into the shared session. Visible faces, edges, vertices and object occurrences are selectable; clicking a selected entity removes it, modifiers add/remove, double/triple clicks reuse the existing connected/coplanar/edit-instance rules, and ALT-click selects an occurrence.
- Added native marquee selection with projected geometry checks: left-to-right selects targets contained by the window, right-to-left selects targets touched by the crossing region. The viewport shows blue Window and green Crossing overlays, selected faces/edges get non-shadow-casting highlights, and the inspector reports selected object/face/edge counts.
- Staged point tools now receive camera-ray world coordinates and snap to existing visible geometry (including locked geometry) before using the document grid as a fallback. Paint edits the picked face or edge. Escape closes an open command palette; otherwise the shared Escape behavior clears selection or guides, cancels the active tool, and returns to Select.
- Right-drag orbits the camera; the wheel zooms. Camera pitch is clamped to ±89°.
- Added tests for palette registry search, native session command dispatch and resulting render-source geometry, plus mesh conversion, bounds, counts, empty batches, lighting defaults and back-face tint.

## Remaining acceptance work

- Port floating/dockable toolbars, right-click context menu and interactive inspector/domain settings.
- Replace the current document-traversal ray picker with GPU or accelerated spatial queries suitable for larger scenes; port the persistent oriented cursor and guide placement to Bevy.

## Validation

`cargo test --workspace --quiet` passes (214 core, 231 desktop, 15 IO and 5 CLI tests); `cargo clippy --workspace --all-targets -- -D warnings`, `cargo check -p meshcraft-desktop --lib --target wasm32-unknown-unknown`, formatting, `verify_plan.py` and `git diff --check` pass. The focused native Bevy suite covers legacy toolbar group coverage, active/disabled toolbar and palette presentation, disabled-reason feedback, embedded icon atlas regions, selector containment/crossing, shared click semantics, nearest ray face and geometry snap, palette registry search, JSON object parsing, schema display, typed cuboid payload dispatch and rejection feedback, shared command dispatch and rendered-document updates. Earlier coverage also tests palette refresh scheduling and mesh conversion/bounds/counts/empty batches/lighting defaults/back-face tint. The native app starts on the NVIDIA Vulkan adapter. The 2,000-entity frame/hover/pick/edit measurements remain required before T57 can be completed; do not report an improvement over issue #18 until they are recorded.
