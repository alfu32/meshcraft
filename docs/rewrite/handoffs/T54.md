# T54 handoff — Persistent oriented cursor and context-safe guide placement (#8, #9)

Status: complete. T11 snapping/guides, T13 tool state, and T51 geometric feedback are complete.

The desktop viewport now draws a three-axis cursor at its current snapped or free construction point. The basis is shared with construction guides: blue follows the picked surface normal, red is the horizontal tangent through the point, and green is the remaining orthogonal tangent. Positive directions use colored arrowheads; negative directions use lighter strokes.

`view.axis_guide`, `view.grid_guide`, and the G/T shortcuts place guides at the latest cursor point without activating a new tool or resetting tool state. This preserves accepted points and previews during staged operations and does not change document geometry/history. If the cursor has not acquired a viewport point, an in-progress tool is retained and the command reports the missing point. With Select active, the existing one-click guide-placement path remains as a fallback.
