## Raylib helper integration — 2026-10-19

`gpui_helpers.rs` uses the same camera projection as the viewport for pixel-radius snapping. It distinguishes grid intersections, continuous grid-line points and free points; it also snaps to translated/tilted guide grids and axes, preserving geometry endpoint/segment precedence and rejecting helpers behind a picked solid face. Surface grids remain on the actual picked plane. All construction and modification tools consume the resulting session point input. Grid guide rendering uses all three planes and the configured spacing instead of a hard-coded single plane. G/T and View ribbon helper buttons share the existing context-safe placement commands. GPUI now owns an explicit root focus handle so Escape and guide keyboard input reach the shell.

Automated checks cover X/Y/Z workplanes, tilted and translated guide lattices, axis points, grid-line positions, free placement outside tolerance, endpoint precedence and surface-plane retention. The shared Escape tests cover tool cancellation preserving selection/guides, then selection clearing, then guide clearing. Issue #14/#15 visual marker acceptance remains open.
