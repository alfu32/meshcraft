# T37 / T38 — Extended interchange and IFC proxies

## 0.24.0 — Implemented subsets (2026-10-22)

All extensions formerly listed by the deferred import/export commands now have
working converters. The [user guide](../../interchange.md) records exact subsets,
unit/axis conventions and loss diagnostics. Core and IO remain independent of GPUI,
raylib and JavaScriptCore.

- glTF/GLB: validated glTF 2, strided/indexed local/base64/binary buffers, repeated
  node instances and nested transforms, reflected winding, triangles/strips/fans,
  line modes and base RGBA. Export produces self-contained glTF/GLB with geometric
  normals, RGBA materials and line primitives. Sparse accessors and evaluated
  skin/morph/animation are outside this subset; texture data is not loaded.
- ASCII FBX: static polygon arrays and 7.4 mesh output. Binary FBX and node
  transforms fail explicitly; the pinned legacy implementation also supported
  ASCII arrays only. Materials/hierarchy/animation are not retained.
- Collada: source/accessor stride and offsets, triangles, concave polygon/polylist,
  linework, visual-scene instancing and ordered affine transforms, physical units.
  Controller/instance_node and polygon-hole constructs fail explicitly.
- 3MF: bounded ZIP/OPC model XML, root relationship, mesh-resource indices, nested
  components/build transforms, mirrored winding and units. Export checks degenerate,
  open, non-manifold and inconsistently wound edges before writing a valid package.
  Materials and extension geometry are outside this subset.
- AMF: XML/ZIP, object-scoped vertex indices, volumes and units. Constellations are
  rejected rather than flattening them incorrectly. Output is triangle mesh XML.
- IFC: STEP tessellated/polygonal face sets, faceted BREP, polylines and local
  placement chains. Comments/quoted strings are parsed independently of entity
  delimiters. SI prefixes, source face-bound orientation and physical geometry
  are retained. Unsupported solids/mapped representations are diagnostic. IFC4
  output has project/site/building/storey spatial containment and named geometry
  proxies; it does not claim editable IfcWall/IfcSlab or semantic BIM fidelity.

The committed Khronos Box GLB is an independent scene fixture, with its Cesium
CC-BY-4.0 attribution. The committed FBX fixture matches the pinned legacy file's
SHA-256. Hand-authored XML/STEP/ZIP fixtures test transforms, independent resources,
units, BREP orientation, concave polygons and malformed input, rather than relying
only on self round trips. A closed tetrahedron independently checks bounds and
signed volume through all twelve encoding variants. See
[fixture provenance](../../../crates/meshcraft-io/tests/fixtures/README.md).

Reproducible read-only external-file probe:

```sh
cargo run -p meshcraft-io --example probe_interchange -- \
  ../k3d/examples/export.obj ../k3d/examples/export.stl \
  ../k3d/examples/carcass_08_div_int.fbx ../k3d/examples/planetary_gear.dxf \
  ../k3d/examples/carcass_01_right.3mf ../k3d/examples/carcass_stair.amf
```

The broad third-party DCC/CAD corpus and Windows/macOS native qualification remain
open acceptance work; T37/T38 stay in progress for that qualification. The working
subset implementations and native/MCP command wiring ship in this release.
