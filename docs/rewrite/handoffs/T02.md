# T02 handoff

Status: in progress. T01 and the T46 normalization gate are complete.

- Added robust f64 `Vec2`/`Vec3` operations, including scale-stable lengths and normalization. `Affine3` now normalizes its linear matrix before inversion, preserving uniform tiny/huge scales while rejecting singular, ill-conditioned, and nonfinite results. Point, vector, and inverse-transpose normal transforms remain distinct.
- Added source-specific legacy tolerance constants and quantization rules. Line/face keys use ties-to-even; hotspot keys retain ties toward positive infinity. These policies are separate from generic predicate tolerances and screen-space snapping.
- Added `ModelUnitScale` conversions for display lengths, unitless/physical export scale, and legacy 3MF millimeter input. `ModelSettings::unit_scale` exposes the conversion without rescaling authored coordinates.
- Added `Segment2` intersection results for disjoint, point/touch, and collinear-overlap cases, plus `Triangle3` normal, area, barycentric, and point-containment queries.
