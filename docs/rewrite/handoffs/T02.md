## Displayed units without rescaling geometry — 0.23.1 (2026-10-22)

ModelSettings centralizes presentation conversion: displayed length is internal
length × unit_size, suffixed by unit_name. One grid step therefore displays
`grid_size * unit_size`; cm/30/0.5 yields 15 cm. Changing grid size does not
multiply an arbitrary stored length again. Existing physical export conversion
is retained. Coordinates, numeric tool input, architecture parameters and saved
geometry remain in internal units.

Point/vector, primitive-radius, Push/Pull, architecture-control and hotspot
feedback now use the display scale. Automatic dimension labels use it while
custom annotation text stays unchanged. Architecture defaults and selected-owner
length rows show the internal input, “units”, and the converted result; inclination
stays in degrees. Model/path length settings show converted values, grid size
also explains one grid step, and snap radius is labeled px. MCP contract and
scripting API descriptions state these coordinate and presentation rules.
