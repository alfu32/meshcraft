# T12 handoff

Status: complete. T03, T10 and T11 are complete.

Scope: implement mixed-entity selection and semantic picking. Preserve separate screen-window, crossing and world-volume workflows; use an injectable clock for double/triple-click behavior; enter object definitions on double-click; and centralize per-type display, lock and wireframe policy for rendering, picking and snapping. Add a shared contract for domain-provided semantic handles and consistent selection summaries/counts.

Progress: selection supports typed vertices, edges, faces, objects and semantic handles with atomic replace/add/remove, occurrence-scoped contexts and per-kind summaries. Shift adds, Ctrl/Cmd removes, and a plain click toggles an already selected entity off while preserving other selected targets. A live blue left-to-right marquee selects fully contained geometry; a green right-to-left crossing marquee also selects geometry crossed by the region. Alt forces containment mode. Timed face double-click selects only the edge-connected coplanar triangle region; connected line double-click, connected-component triple-click and instance edit entry remain supported. Triple-click on a line or triangle selects all connected vertices, segments and faces. Drawing inside an entered instance appends geometry to its definition in local coordinates. Visibility, lock and wireframe policy is shared by viewport drawing, click/window/volume picking and snapping. A provider contract dispatches world-space domain handles through active contexts and an occlusion-aware projection callback. Orthographic depth ordering now chooses the nearest face and suppresses edges behind it.
