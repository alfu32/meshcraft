# T30 Handoff — In progress

## 0.16.0–0.18.0 — Independent windows and doors

Window and Door use their own architecture definitions and placements. Two-corner
input or a selected closed contour produces the frame; defaults are depth 0.12,
frame width 0.06, new-window glazing enabled and new-door glazing disabled.
Persisted omitted glazing remains disabled for legacy compatibility. The shared
Architecture panel edits dimensions, colors, glazing and name. Frame creation,
movement and deletion never implicitly cut a wall or slab. Openings require
explicit Add Hole on that owner.

Native frame picking selects the independent object, with normal prototype-edit,
copy/placement and explode workflows. Explode retains realized mesh and removes
derived-cache attribution so exported geometry survives reopening. Canonical
frame parameters regenerate on load. The broader architecture validation and
captures are recorded in [T29](T29.md).

This checkpoint does not implement stair generation or the remaining legacy frame
corner/edge controls. T30 remains in progress.


## 0.20.0 — Frame resizing and cursor orientation

Two purple opposite-bounds controls resize rectangular or freeform frame contours
on their definition plane. The shared command/pointer path keeps frame width and
depth unchanged and rejects collapsed input. Window input takes its first plane
normal from the cursor, including non-face snaps. Native X-normal placement,
resize preview/cancel/undo, frame-instance explode/undo and save/reopen passed.
MCP publishes control descriptors alongside canonical records. See the latest
[T29 validation](T29.md) and [frame capture](../references/architecture-controls/frame-controls.png).
Stair generation and additional legacy edge/center controls remain outside this
checkpoint; T30 stays in progress.

## 0.38.0 — Contour/path stairs and #29 material assignment

The stair generator/input/control slice is delivered by [T67](T67.md): C/P source
objects or edge selections, exact editable height, configurable left/right guide
copies, closed shell generation for straight/L/U/curved flights, phantom height
dragging, materials, clipboard/transforms/explode and canonical persistence. New
height defaults to 10; stored legacy dimensions and four omitted legacy guide
levels remain compatible. See [the current guide](../../architecture.md).

The aggregate T30 task retains its earlier broad source/legacy qualification
status; the user-requested stair implementation is complete in T67. The historical
frame-wrapper descriptions above were superseded by the semantic frame ownership
contract in [P03](../spec/modeling.md#p03-stairs-window-frames-and-door-frames).
