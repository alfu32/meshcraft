# T18 native annotations — partial delivery, 0.11

D05 / C14: native Dim (start/end/offset), Text (placement), and the newly requested three-point
Leader have construction preview, relative input feedback, GPUI labels and offscreen line/arrow
geometry. Compatible domain records retain IDs, text size and plane metadata. The Annotations
accordion edits defaults or selected properties. Bitmap labels are billboarded; plane-oriented
glyph rendering and D06 vector-text construction/catalog authoring remain outstanding, so T18
is in progress rather than complete.

Annotation records participate in click and window/crossing picking, selection display policies,
prototype edit isolation, geometry transforms/copies, deletion, undo, clipboard and serialization.
Leader paths are transformed by the same annotation-record helper used by copy/arrays/explode.

Validation: `cargo test --workspace --lib`; `cargo clippy --workspace --all-targets -- -D warnings`;
`cargo build -p meshcraft-desktop`; `python3 docs/rewrite/scripts/verify_plan.py`. Exact results and
native visual evidence are recorded in the T60 follow-up after final integration verification.
