# T11 handoff

Status: in progress. T02 and T03 are complete; T10's camera work is implemented but its full acceptance matrix remains open. This capsule records geometry snapping and the first guide-placement workflow.

The desktop viewport now returns construction-point snap candidates for Line, Rectangle, Grid Guide, and Axis Guide input. It considers endpoints, segment midpoints, closest points on segments, ray hits on triangles, grid intersections and grid lines on the nearest hit surface plane or, when no face is hit, the active perspective/orthographic construction plane. Candidate arbitration uses the legacy priority bands together with screen distance and camera depth. Model `snap_radius` is treated as physical pixels and converted to egui points at the active device scale. Candidate traversal covers transformed and nested occurrences; cached world bounds cull off-screen content. A colored ring marks non-free snaps, and completed Line operations report the snap kind.

The palette commands `view.grid_guide` and `view.axis_guide` activate one-click placement; G and T provide the legacy shortcuts. Guides use the picked surface normal, preview under the pointer, draw as construction overlays, and participate in grid/axis snapping. They are session state, separate from authored geometry, and clear when a new scene is installed.

Permanent grid settings now include X/Y/Z normal selection and the reference 1–1000 step extent. The configured normal controls the perspective virtual construction plane and grid basis; orthographic construction planes remain view-aligned. Rendered grid lines downsample adaptively below 8 screen pixels per step while retaining major-line cadence. Existing saved preferences default to Y-up, and legacy `x_right`/`y_up`/`z_back` values remain readable. A temporary local grid cloud appears when a snap approaches the permanent grid edge, lies outside its extent or plane, or a grid guide exists. It follows the snapped surface normal, stays anchored within a seven-cell radius, and clears when snapping ends; it never changes the scene graph.
