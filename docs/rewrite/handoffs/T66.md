# T66 — #29/#30 Shader editor tabs, highlighting and GPU preview

Status: **Complete**, 0.37.0 · P07 · C42.

## Delivered

- Match the object script editor's full-window footprint, retaining window chrome.
  Equal-width code/preview panes replace the small fixed-size program dialog.
- Definition (JSON), Vertex (GLSL) and Fragment (GLSL) tabs each retain their own
  input state. All use monospace code editors. The existing JSON grammar and pinned
  `tree-sitter-glsl` 0.2.0 provide local syntax highlighting. GLSL keywords,
  qualifiers, types, functions, constants, comments, uniforms and time are colored;
  a shared theme preserves JavaScript declaration highlighting.
- Debounce typing by 300 ms and provide Preview for immediate refresh. Use a cube
  for surface programs, a plane for subdivided/scattered surfaces and an independent
  owner for trees, with actual renderer lighting/shadows and animated uniforms.
  Orbit/pan/zoom use the object editor's controls and an independent camera.
- Private preview documents never enter session history, selection or the authored
  drawing. Reuse the existing single offscreen graphics worker and retire the
  preview on Cancel/Escape/Save. Camera motion does not rebuild preview geometry.
  Only consume compiler diagnostics from a frame at least as new as the draft.
  Invalid JSON leaves the last preview visible; invalid GLSL shows compiler/linker
  diagnostics and the conventional fallback. Save waits for a successful preview.
- Save Program retains the explicit undoable document edit, preserves compatible
  parent material parameter values, and returns to the material/object editor.
  Updating a program still respects core validation and immutable built-in IDs.

## Limits

Live native UI/GPU qualification covers Linux x86_64 software Mesa/OpenGL 3.3.
Windows, macOS and hardware GPU drivers require their native qualification. Preview
uses a small representative private scene, with the current material values;
it does not render the full active drawing. Shader sources still use the existing
GLSL 330 hook contract and generation modes. Broader #29/#31 scope remains open.
