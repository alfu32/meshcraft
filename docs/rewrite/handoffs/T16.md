# T16 — Reusable objects, placement and explode

Status: in progress. T12, T15 and T46 dependencies are complete.

Implemented selection-first grouping for object occurrences and supported mesh selections, parent-local nested duplication, one-pick definition placement with optional surface alignment, mesh-only explode/materialization with result selection, and deletion of unused definitions. Grouping selected dimensions and text with mesh now moves their legacy DTO arrays from the source definition into a shared hybrid child definition without changing local coordinates or payloads. Desktop commands include `object.create_from_selection`, `object.place_selected_definition`, `object.toggle_place_glue`, `object.explode_selection` and `object.delete_unused_definition`. Core APIs are in `operations::objects`; placement state is in `tools::object_place`.

Shared interaction rules remain explicit: click selection can target objects and typed mesh entities; left-to-right screen windows require full containment, while right-to-left crossing windows include intersections. Escape clears a nonempty selection, otherwise clears guides, and always cancels the active tool and returns to Select. Every active point-input tool uses the shared snap resolver for grid and existing geometry, including transform and object-placement picks; Cuboid base/elevation picks consume snapped coordinates.

Validation: `cargo test --workspace --quiet` passes (205 core, 193 desktop, 15 IO, 5 CLI), including mixed mesh/dimension/text grouping, DTO retention, visibility through shared definition instances, and atomic rejection of moving inherited annotations from one placed occurrence. `cargo clippy --workspace --all-targets -- -D warnings`, the desktop WASM check, formatting, `git diff --check` and `verify_plan.py` pass.

Remaining: inherited annotations can be grouped only while editing the scene root or their active definition; occurrence-level overrides need typed semantics. Hotspots and other domain payloads still need grouping/copy/explode adapters, and explode currently supports mesh-only content. Complete C08 mixed-payload lifecycle coverage and C32 normalized/effective-content equivalence before marking T16 complete.

Changed paths: `crates/meshcraft-core/src/operations/objects.rs`, `DASHBOARD.md`, and this handoff.
