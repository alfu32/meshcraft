# T32 — Object prototype workflow (in progress)

Implemented 2026-10-20: the Objects browser lists prototypes with occurrence counts and double-click insertion. Wireframe previews resolve the complete subscene without depending on a selected source instance. Double-clicking an instance enters its prototype; editing uses an authored view, faded surroundings, external snapping, isolated selection, Escape and Finish Editing.

Hotspot authoring goes through shared document transactions: name, operation, shape, RGBA picker, geometry/handle attachments and reference points. Runtime instance handles are screen-sized; dragging previews absolute values and commits once. Prototype editing selects/authors handles; operating them requires leaving prototype editing.

User explanation and all captures: [objects.md](../spec/objects.md). Core APIs: `Document::hotspots`, `put_hotspot`, `delete_hotspot`, `set_hotspot_target`, `evaluate_hotspots`, `prototype_edit_view`. GPUI hosts those APIs through `object_workflow.rs` and `gpui_hotspots.rs`.
