# T75 — Tutorial video suite

Status: **Complete**, 0.53.0 · C48. Sources and rules: [docs/tutorials](../../tutorials/README.md).

## Delivered

- Five narrated tutorials with a selectable English subtitle track and `.srt`/`.vtt` copies, built locally by
  `scripts/video/build.py`, `voice.py` and `assemble.py` from recipes in `docs/tutorials/recipes`.
- MCP native pointer: `k3d_pointer_event` gains `hover`, `down` and `up`, which run the mouse's own handlers, so
  MCP places the snapping 3D cursor, picks, draws the selection window and drags handles.
- `k3d_status` reports `cursorSnap`, `constructionGuides`, `workspace.viewport` and `camera.distance`.
  `workspace.controls` gains `tool/<tab>/<command>` for ribbon buttons and `setting/<label>` for settings fields.
- `k3d_pointer_event` takes an optional surface normal for world `click` and `move`.
- Fix: the construction cursor kept a fixed size of 0.65 model units, which is a speck in a centimetre project.
  It now keeps a constant screen size at any model scale.
- Fix: Door and Window snapped to an opening's corner lay flat, because that snap reports an upward normal. A wall
  or slab under the cursor now decides their plane.

## 0.53.1

Tutorial 3's line "On the Materials tab..." had a 20.48 s clip for about 5 s of words: the speech model ran away and
repeated sounds to the end of the clip. It was reported by listening, regenerated at 4.88 s, and tutorial 3 was
re-recorded for the new pace. `voice.py` now retries a clip below 6 characters per second and fails after three
attempts. A check for repetition in the loudness pattern did not flag the known bad clip, so it was dropped; clip
length is the only tested signal. Four clips run slow at 7.1 to 7.6 characters per second and have not been listened
to by the author of this work: tutorial 1 at 65 s and 171 s, tutorial 3 at 25 s and tutorial 5 at 78 s.
