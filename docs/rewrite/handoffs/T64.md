# T64 — #29/#31 Shader trees, water, brick and wood

Status: **Complete for this four-preset request**, 0.35.0 · P07 · C42.
The broader [#31](https://github.com/alfu32/meshcraft/issues/31) remains open for
bush/source-domain and broader procedural-object qualification.

## Delivered

- Immutable built-in typed shader resources for Water, Brick, Wood and Tree,
  reusing T63's declarations, editor, shader cache and GPU source-domain buffers.
- Water uses bounded GPU triangle subdivision, analytic wave normals,
  animation, configurable surface offset, transparent shading and Fresnel sky
  approximation. Brick has continuous local running-bond/mortar patterns;
  Wood has solid-coordinate rings/fibers and selectable grain axis. Both support
  seeded variation, colors and derivative shading relief.
- Independent Tree prototypes and instances contain settings and empty authored
  geometry. GLSL emits tapered cylinders and cutout leaf cards in separate draws,
  bounded by branch/leaf budgets with deterministic seed, foliage LOD and wind.
  Compiled shaders and identical domain buffers are reused. Prototype defaults
  and complete private instance settings are separate.
- New Tree / Edit Tree in Object Prototypes; Edit Procedural Tree in Object
  Instance; double-click opens the parameter editor. Shared typed editor supplies
  Apply/Save/Cancel, range checks, reset, LOD, candidate budget and bounds controls.
  New Water / New Brick / New Wood are available in Materials and command search.
- Bounds integrate with camera fit, spatial picking, window selection, selection
  boxes, wireframe placement/transform/clipboard feedback and shadow framing.
  Mesh-free bounds compete by depth with background model faces when picking;
  a regression covers a wall behind the tree.
  Unsupported programs preserve owners and render diagnostic bounds. Existing
  object transforms, hierarchy and copying retain settings without CPU tree meshes.
- Material/base/program imports remap references and protect used base materials.
  The schema-17 adapter explicitly restores procedural instance records from its
  flat field envelope, including prototype child-layout defaults. Qualification
  caught and fixed lost instance values on reopen and confirmed editing/re-saving
  imported empty-layout tree prototypes.
- MCP publishes preset schemas, owner settings/classification/bounds and the
  transactional `object.configure_procedural` interface.
- [Workflow, pictures and limits](../../procedural-presets.md),
  [example](../../../examples/procedural-presets.octd), and
  [recorded native/GPU evidence](../references/procedural-presets/validation.json).

736 regular tests pass: core 312, desktop 377, CLI 5, IO 42; 14 opt-in/manual tests
are excluded by default. Strict Clippy, native build, format, plan validator and
8 release-helper tests pass. Wasm library check passes with its 3 existing unused
native API warnings. Cargo also reports the existing proc-macro-error2 future
compatibility notice.

Under a private display, with `DISPLAY=:97 LIBGL_ALWAYS_SOFTWARE=1`:


All 7 GPU checks pass: persistent buffers, projected shader lines, light/shadow
composition (analytic shadow IoU 0.919), placement, grass/fallback, the four new
presets, and surface texture/PBR/instance sharing. Framebuffer PNGs were visually
reviewed; BGRA renderer readback is encoded as RGBA for the standalone PNGs.

Native GPUI qualification used a private Xvfb :96, private configuration/cache,
xdotool, and the real MCP endpoint on localhost:18766. It creates three material
surfaces and two tree instances, copies/pastes a tree, changes one instance,
checks sibling isolation, Undo/Redo, Save/Open, draft cancellation and
parameter-editor double-click routing. GPU animation advances without document
revision changes; disabling wind/waves idles the renderer. Water animation changes
captured pixels without model edits. The final view reports 6,647 procedural
candidates in 7 draws; each tree has zero authored vertices/triangles. The user's
`demo.octd` and running application were not touched.

## Limits

Water approximates sky reflection; it has no scene reflection/refraction,
physical water depth or fluid simulation. Brick/wood relief is shading only.
Generated foliage/branches/waves remain GPU visuals, with no CPU baking,
leaf/branch snapping, collision or generated mesh export/Explode. Tree interaction
and phantoms use conservative owner bounds. Hardware drivers, Windows and macOS
were not live-qualified in this environment. This task does not close the broader
#29/#31 umbrella or add compute/mesh shaders or the bush reference example.
