# T10 handoff

Status: in progress; T07 remains in progress. This records the orthographic-camera slice without claiming full T10 completion.

`Viewport` now has distinct top, bottom, left, right, front, and back orthographic bases. Their projections keep screen scale constant along camera depth, and the same projection drives rendering, depth ordering, fit-to-document, and pixel-space picking. Mouse-wheel zoom anchors the view-plane point beneath the pointer; secondary and middle drags pan. Six `view.ortho.*` commands now switch views, expose checked state, and do not mutate the document. The legacy orthographic command selects top view; reset returns to the default axonometric view.

Ground-plane tools receive valid coordinates in axonometric and top/bottom views. Side/front/back views report that the ground-plane operation is unsupported instead of fabricating a point. Height entry is rejected when the active projection cannot show vertical height.

Checks: `cargo test -p meshcraft-desktop --lib` passes (44 tests), including all six projection bases, depth-invariant scale, ground-plane inversion, orthographic picking, visible-height inversion, and command dispatch/state.

Changed paths: `apps/desktop/src/{app.rs,viewport.rs}`, `docs/rewrite/tasks.json`, `docs/rewrite/handoffs/{T06.md,T10.md}`.

Remaining: true perspective camera and target semantics, walkthrough movement/support/gravity/jump preferences, persistence boundaries, six-view construction planes, focus/DPI/menu mapping, and full C09 checks. Keep T10 in progress.
