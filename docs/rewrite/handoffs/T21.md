## Legacy input matrix (source inspection)

`MultipleCopyTools.kt` builds transforms from the current selection and restores that source before each copy step. Supported source payloads include mesh, object/group placements, dimensions, text, voxels, architecture and HVAC data; Rust currently copies mesh and root object occurrences.

| Tool IDs | Ordered picks | Count and endpoint behavior |
| --- | --- | --- |
| `COPY_MULTIPLE` | U reference, V step/measure, D span end | Copies at positive integer multiples of UV that fit in the projected span; excludes the source and does not overshoot. |
| `PLANAR_TRANSLATE_MULTIPLE` | O origin, A XZ step, B extent | XZ grid; floor each axis count and exclude the origin cell. |
| `VOLUMETRIC_TRANSLATE_MULTIPLE` | O origin, A XYZ step, B extent | XYZ grid; floor each axis count and exclude the origin cell. |
| `PLANAR_ROTATE_MULTIPLE`, `HELICOIDAL_ROTATE_MULTIPLE`, `ROTATIONAL_ARRAY` | C center, U reference, V angular increment, W sweep end | Fixed signed angular step; floor copies within sweep. Helicoidal mode distributes W's axial lift across copies. A planar full revolution omits the duplicate source position. Rotational Array uses A/B/D prompt labels. |
| `ROTATE_2` | C center, A reference, B end angle | One rotation, or one rotated copy when copy mode is active; it is not a multi-copy tool. |
| `HELICAL_ARRAY` | C center, A reference, B helical unit, D sweep/height end | Fixed angle and Y lift from A→B; count resolves to the requested sweep/height, omitting a duplicate planar full-circle position. |
| `ROTATIONAL_ARRAY_EQUALIZED` | C center, A reference, B angular hint, D sweep end | Partial sweep retains the angular hint; a full-circle request derives equal spacing from selection span and radius. |
| `HELICAL_ARRAY_EQUALIZED` | C center, A reference, B helical unit, D sweep/height end | Equalizes circular spacing; for a full-circle request, estimates turn count from requested height and pitch. |

The source caps committed multi-copy steps at 2,048 and preview steps at 10,000, reporting when output was capped. This is static source evidence, not a live legacy runtime comparison.

Implemented `operations::copy::linear_array` for selected mesh entities, root object occurrences, and mixed selections. Each copy is transformed from the original selection, the source remains unchanged, and generated results replace the selection. Invalid counts, zero/non-finite steps, and unsupported targets fail atomically. The `object.array_selection` palette/menu action and numeric preview now accept mesh selections and keep command enabled state aligned with supported targets. Nested object occurrence copies remain disabled.

Implemented `ROTATE_2` as a separate three-point transform: C/A/B derive the axis and signed angle; optional copy mode creates one rotated result while preserving the source. It has staged prompts, preview, selected output, and undo. Implemented `COPY_MULTIPLE`, `PLANAR_TRANSLATE_MULTIPLE`, `VOLUMETRIC_TRANSLATE_MULTIPLE`, `PLANAR_ROTATE_MULTIPLE`, `HELICOIDAL_ROTATE_MULTIPLE`, `ROTATIONAL_ARRAY`, and `HELICAL_ARRAY` as toolbar/palette tools over selection targets. Copy Multiple consumes snapped U/V/D picks and places fixed-vector copies only at positive integer steps that fit the projected span. Translation arrays consume snapped origin/step/extent picks and fill signed XZ or XYZ grid cells. Rotational tools consume center/reference/increment/sweep picks and apply signed fixed-angle transforms. Planar full circles omit the duplicate source position; Helicoidal Rotate Multiple distributes its measured lift across the sweep. Helical Array uses the legacy world-Y axis and fixed angle/lift from A to B to resolve the requested sweep and height. Committed copies cap at the legacy 2,048-step limit, previews cap at 10,000, source geometry stays intact, and generated targets replace selection. Tool availability tracks supported selection, each computed transform previews, Backspace removes staged picks, and Escape resets the tool.
