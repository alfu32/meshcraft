# T17 — Inspectors, settings, preferences and menus

Status: **In progress**. The native Bevy inspector is being brought into parity with the reference panels; C17/C23 and dependencies T08, T09 and T16 remain open.

## Implemented

- The eframe inspector has a scrollable Panels accordion for selection, object/prototype, model and tool settings, preferences, lighting, tutorials and help. Model settings are document-owned, validated, revisioned and undoable; application preferences are persisted separately.
- The Bevy sidebar has the reference Selection table with per-type totals, selected counts, display and modifiable controls, and face wireframe. These controls dispatch `selection.update_display`, which is also available in the command palette; the shared policy keeps picking, snapping and selection windows aligned with visibility and locks, including hidden object instances. Face visibility and wireframe update GPU batches, with wireframe in a separate non-shadow-casting line batch. Model Settings exposes unit name/size, grid size, circle segments and snap radius; the separate Polyline Settings section edits arc length and double-line size/offset. Each Apply button dispatches `model.update_settings` through shared validation, transaction and undo. Focused drafts survive unrelated document revisions, and “Edit as JSON…” remains available for structured editing.
- Bevy UI Settings now edits text scale, toolbar icon size and flow, toolbar auto-collapse, permanent-grid visibility/orientation/extent and normal/thick pixel widths, and construction-guide visibility through `ui.update_preferences`. Retained Bevy gizmo batches apply the two grid widths while keeping the grid depth-tested and outside the shadow pass. The grid and toolbar presentation respond immediately, and native settings persist under the platform configuration directory. Independently draggable toolbar positions use the same preferences command, restore across launches, and reflow/clamp on resize.
- The native Object inspector follows a single selected occurrence, supports transactional and undoable renaming, and displays top-level object instances as selectable rows. A row click selects its instance; a quick second click enters that instance's edit context. Rows and selected-state styling refresh after document and selection changes.
- The supplied eight right-hand panel screenshots were checked byte-for-byte against retained references. Domain-specific architecture, HVAC, hotspot, random-tool and tutorial sections remain reference-only until their feature adapters are implemented.
