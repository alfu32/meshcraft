# T65 — #29/#30 Foliage scattering and shader color pickers

Status: **Complete**, 0.36.0 · P07 · C42.

## Delivered

- Every shader `color` parameter uses the existing HSL/RGB/swatch picker with
  opacity, for material settings, tree prototype/instance settings and custom
  programs. Numeric RGBA array entry is replaced by picker controls. Conversion
  to normalized RGBA happens behind the UI; model/MCP/project formats remain
  unchanged. Untouched colors keep their original precision through Save.
- Parameter Reset updates the picker and its backing value. Read Selection Values
  loads assignment colors into both. Picker subscriptions belong to their draft
  field and retire with it. Save/Apply/Cancel retain the existing scopes.
- Foliage is a built-in GPU surface-scatter program with density, leaf length,
  width, height, edge spread, tilt, curl, wind, brightness variation, seed and two
  leaf colors. Broad curled strips have a pointed cutout and procedural veins.
  Tangent-plane root offsets distribute leaves beyond source boundaries.
- Reuse the existing GPU domain cache, seeded distribution, transformed expanded
  bounds, frustum rejection, density LOD, work budgets and shadows. No leaves
  become authored geometry, snap targets or generated mesh exports. Zero wind
  idles the viewport. Color parameter opacity now selects the transparent pass
  for every procedural program, including objects, and prevents opaque shadows
  from translucent generated details.
- New Foliage in Materials and command search; the same material assignment and
  per-selection override interfaces apply. MCP publishes `meshcraft.foliage.v1`
  and its `foliage` generation/parameter schema.
- [User guide and pictures](../../procedural-presets.md),
  [example](../../../examples/foliage-colors.octd), and
  [recorded native qualification](../references/foliage/validation.json).

## Limits

Generated foliage is visual and uses its source for picking/snapping. It is not
baked by mesh export or Explode. Alpha uses the existing viewport blending path,
without order-independent transparency. Live GPU/UI qualification covers Linux
x86_64 software Mesa/OpenGL 3.3; hardware drivers, Windows and macOS were not
live-qualified here. The broader #29/#31 scope remains open.
