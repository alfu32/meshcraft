## 0.16.0 — Canonical architecture solids and owned openings

Added typed wall, closed-polyline slab, opening and window/door frame records in
`document::architecture`, using compatible architecture arrays on definitions.
The rectangular slab representation is the same closed polyline as a freeform
slab. Slab profile edits preserve a stable local plane for owned opening UVs.
Polygon subtraction handles concavity, overlapping/edge-clipped openings and
reveals. Frame borders/glazing generate independently of wall/slab records.
Generated edges/faces carry semantic owner attribution and are separate from
loose authored geometry. Export strips those caches; import rebuilds valid
records once. Invalid/unknown legacy payloads remain preserved.

regressions for volume/winding, concave slabs, opening union and deletion,
invalid-edit atomicity, stable opening planes, independent frame geometry and
legacy round trips. Core Clippy and formatting pass. The plan verifier passes.

Remaining: drawing tools/command payloads, live settings, semantic selection and
editing, and native slab profile controls. T30 remains in progress: frame data
and geometry are present, while stair tools remain outside this request.

## 0.17.0 — Commands, drawing and native properties

Wall chains, Rectangular Slab, Freeform Slab, Add Hole, Window and Door now route
through the shared session. Rectangle/freeform slabs share closed-polyline data;
freeform input supports A/C/L and closes with Enter. A selected closed polyline
can be used directly for slabs or free-form frames. Hole input locks its first
picked wall/slab owner. Plane locking, solid previews, relative measurements,
undo and type visibility/editability use the shared viewport/session path.
Windows and doors are placed as independent architecture prototypes/instances;
new windows enable glazing, new doors do not. Frame picking retains normal
object-instance selection/edit behavior for standalone frame definitions.

The Architecture panel edits selected parameters or persisted defaults, with
name, dimensions/inclination, colors/glazing and deletion of individual owned
openings. Colors apply together as one edit. Generated facets select their
semantic owner; normal mesh Face visibility does not hide architecture surfaces.
Selection-table counts use the actual architecture array names and exclude
regenerable facets from loose mesh totals. Structured `architecture.*` command
payloads are published through the normal command catalog, including MCP.

`cargo test --workspace`: **567 passed**, two opt-in renderer probes ignored.
Strict workspace Clippy, formatting and the plan verifier pass. Eight new session
checks cover drawing/feedback, shared slab representation, independent frames,
locked opening ownership, undo, ray-pick visibility, atomic failed property
changes, semantic deletion and vertical-plane slabs. Native pointer/UI review
is deferred to the following profile-control checkpoint. Remaining in this
request: native slab control dragging and edit-operation integration checks.


## 0.18.0 — Slab controls, edit integration and native qualification

Selected slabs expose screen-sized blue controls at their polyline vertices.
Dragging locks to the slab plane, previews a private snapshot, displays relative
coordinates/distance, and commits once on release. Escape restores the original;
invalid profiles leave the document/history unchanged. The frozen owner plane
keeps existing openings fixed during profile edits. Type editability and active
prototype context gate the controls.

Semantic wall/slab records now participate in move/copy, arrays, clipboard
capture/placement and grouping. Their owned openings transform with the owner.
Rotated walls use their own up axis. Canonical parameters and domain mirrors stay
in sync; copies receive fresh owner identities. Unsupported sheared extrusions
are rejected with an instruction to explode first. Explode clears derived-cache
markers from realized geometry so it persists as authored mesh. Generated facets
are protected from direct edits; MCP exposes their canonical owner targets and
records in `meshcraft_geometry.architecture`. Architecture SVG icons and the
user-facing [workflow/example](../../architecture.md) are included.

Native reopen testing found and fixed an architecture-only scene-root omission:
after stripping the generated cache, root-content detection must still include
canonical domain arrays. Regression tests cover both a root-only model and a root
with independent child objects. The root records, holes and generated counts now
survive a native save/reopen cycle without duplication.

## 0.19.0 — Join, endpoint and control model checkpoint

Walls now store default-on `autoJoin`, signed `offset`, optional `endHeight` and
independent 3D base endpoints. A horizontal axis plus explicit up vector keeps
wall sides upright when the two bases have different elevations. The trapezoid
profile, inclination and owned holes generate closed solids. Neighbor-aware
regeneration meets compatible shared endpoints with miters; multiwall ends use
shared center fans, and acute miters are bounded. Either owner's disabled flag
prevents joining. Property changes/removal rebuild adjacent caches. Runtime
identities keep join grouping safe when legacy canonical IDs are absent/repeated.

Core controls describe wall bases/tops, slab vertices, two opening corners and
two frame bounds corners. Shared control mutations validate before publishing.
Frames resize the full contour on their definition plane; upper wall controls
change only that end's height. Direct semantic architecture explosion preserves
realized join geometry as authored lines/faces and removes the parameter owner.

`cargo test -p meshcraft-core`: **265 passed**, including seven new domain
regressions for sloped bases/unequal tops/offset, corner joins and opt-out updates,
three-way shared centers, endpoint controls, opening/frame resizing and direct
explode/reopen. Strict core Clippy and workspace check pass. Native settings and
control interaction qualification continues in the following checkpoint.

start/end heights. Four wall handles edit bases and tops: base dragging uses the

resize on their owner plane. Multiple selected owners expose their controls.

## Roof profiles and cursor/control corrections — 0.21.0 (2026-10-21)

Wall base/top handles now stay on the canonical axis plane, independent of offset
and inclination. Window/door point input uses the actual displayed blue cursor
axis rather than the snap normal; a line-snap regression deliberately gives those
two vectors different directions.

Slab profiles retain independent heights. Normal dragging adjusts plan position;
Shift-drag uses a view-facing vertical plane and constrains the control along the
slab extrusion axis. Both routes use the same transactional core control command.
A plan triangulation carries the boundary heights, including controls that are
collinear in projection. Roof facets are clipped against owned holes, neighboring
clipped triangles are stitched to eliminate T junctions, and reveals are emitted
only on actual boundaries. Outer sides and opening reveals stay vertical for
Y-normal slabs. Sloped planar roofs retain the specified normal thickness; at
folds the continuous underside preserves at least that thickness, allowing a
thicker junction. Level slabs retain the original single-polygon extrusion path.
Opening UVs remain fixed and their controls follow the roof surface.

Architecture already emits explicit boundary/reveal segments. The native
wireframe/selection outline pass now uses those rather than exposing internal
triangle edges around holes. Ordinary authored-mesh wireframes retain their
triangulation. Regression checks reject artificial wall-face grid segments.
Ctrl-wheel multiplies logarithmic zoom input by 0.5, Alt-wheel by 0.1; Alt wins
when both modifiers are held. The scaling applies before camera-mode dispatch.

## Owner-only drag wireframes and free controls — 0.23.0 (2026-10-22)

Wall/slab control motion no longer clones the full document, regenerates joined
neighbors, or replaces the cached solid scene. `Element::with_control_at` produces
only the candidate owner; its mesh supplies boundary/reveal wireframe feedback.
Unchanged positions reuse that result. The original solid remains visible;
release runs the canonical transaction once and regenerates joins. Invalid
candidates report feedback without changing the model, and Escape discards the
ghost without rebuilding the document cache.

Wall bases and slab profile controls accept arbitrary 3D geometry/guide snaps.
Without a snap they move on a view-facing plane through the grabbed point, rather
than the wall/slab plane. Shift no longer chooses a different movement. Own wall
faces do not trap free dragging. Wall tops retain axial height movement; hole and
frame corners retain their definition-plane constraints. Wall start bases remain
squares, end bases are circles, and both top controls are magenta triangles.
Positions remain on the canonical axis plane.

## Ground-grid control correction — 0.23.1 (2026-10-22)

Free wall/slab controls now snap against actual grid/guide/geometry candidates
before any fallback; the owner's own solid is excluded. Unsnapped movement is
parallel to the active grid at the grabbed point's elevation, replacing the
view-facing fallback from 0.23.0. This prevents a ground-level wall corner from
lifting during plan movement, while elevated references still change height.
Architecture numeric inputs stay internal and display converted lengths beside
them; inclination is labeled degrees. See [the unit contract](T02.md#displayed-units-without-rescaling-geometry--0231-2026-10-22)
and [native ground-grid/screen-radius checks](T11.md#pixel-radius-and-ground-control-snapping--0231-2026-10-22).

## 0.30.1 — Architecture clipboard and explode selection ownership

Reproduced Copy/Explode failures on window and door semantic frame selections in
an isolated native session with a reopened architecture model. Commands treated
the frame as inherited prototype content, rejecting it even though its standalone
instance was editable. A shared command selection adapter now maps such picks to
the owning placement only when that placement is a direct child of the active
graph. Prototype editing retains canonical element selection and shared editing.
Clipboard snapshots preserve prototype identity and instance overrides; mixed
walls/slabs/frame selections work through the same paths. Explode validates the
original and normalized targets against editability before committing.

Copy as Script previously ignored wall/slab semantic targets; it now includes
facets attributed to each selected canonical owner, using current world geometry
and material colors. Tests cover new/reopened drawings, owned holes and surface
material bindings, floating-preview/committed bounds, mixed explode, unaffected
sibling frame instances, Undo, rejected read-only edits and prototype editing.
