# T25 Completion: Primitive Mesh Generators

Implemented staged Sphere, Cylinder, Cone and Pill tools using legacy center/radius/height picks. The core generator clamps radial resolution to 3–256, projects axis-primitive radius picks perpendicular to the picked axis, preserves signed height direction, and builds closed indexed meshes with consistently outward triangle winding. Sphere uses local Y; Pill's third pick is the top hemisphere center.

Desktop command registration now activates each generator. Shared snapped picks drive previews and commits; commits write colored edges/faces into the active scene root or object definition, select the generated entities, and participate in undo. Escape clears the pending picks and returns to Select.

The legacy primitive classes contain no dedicated numeric-entry stage. Dimensions are determined by picks; `circle_segments` controls tessellation. The document derives face normals from triangle winding and has no explicit per-vertex normal field.

Changed: `crates/meshcraft-core/src/tools.rs`, `crates/meshcraft-core/src/tools/primitives.rs`, `crates/meshcraft-core/src/operations/mod.rs`, `crates/meshcraft-core/src/operations/primitives.rs`, `apps/desktop/src/app.rs`, `apps/desktop/src/viewport.rs`, and T25 registry/plan/dashboard files.

Primitive-specific checks cover closed oriented topology, volume, negative height, invalid dimensions, resolution limits, previews, transformed-instance insertion, selection, undo and cancellation.
