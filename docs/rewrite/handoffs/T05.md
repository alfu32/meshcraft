# T05 handoff

Status: in progress; T03 and T46 are complete.

The IO layer reads JSON/gzip projects, normalizes current prototype/instance, prototype-only, rootGroup, and flat geometry shapes, validates the candidate, and retains opaque undo entries separately from model data. The core exports schema-17 prototype/instance snapshots through `legacy::export_current_value`; `project::write_project` adds optional opaque history and applies the legacy 10 MiB compression threshold.

Export expands shared layouts and preserves occurrence IDs, frames, geometry, hotspot edits, model settings, and unknown DTO payloads. Synthetic roots support empty and multi-root documents; generated ID conflicts are remapped deterministically. Typed domain values now map to schema-17 voxel, architecture, HVAC, and hotspot fields, with shape checks and explicit errors for unknown keys. Async Save/Save As omit stale imported history on dirty saves and preserve it on clean saves.

Sparse architecture wall, slab, stair, frame, and nested hole DTOs receive pinned Kotlin persistence defaults during import/export, retaining explicit and unknown fields. The reference creation panel enables frame glazing; an omitted persisted `glazingEnabled` remains false.

Checks: `cargo test --workspace` passes (77 core, 65 desktop, 12 IO). The indexed schema-17 probe passed all 60 fixtures, including the 1,281-placement `docs/tutorial/000_interface.octd`; one documented empty-root zero-basis repair warning occurred for `examples/xref_chair.octd`. Native file dialogs and Kotlin reopen were not manually exercised.
