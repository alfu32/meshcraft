# T05 handoff

Status: partial implementation only; T05 remains in progress and its T03/T46 dependencies are not complete.

- Added `meshcraft_core::legacy::import_current_json` and `import_current_value` for plain current prototype/instance JSON. The adapter preserves prototype and occurrence identity aliases, definition and instance transforms, indexed geometry, colors, child-layout sharing, hotspot positions, instance override geometry, source schema metadata, and selected opaque extension values. It reuses only vertices joined by an explicit legacy alias; it does no implicit coordinate welding or topology repair.
- Desktop startup accepts `--open PATH` or a positional path. It imports read-only, reports errors in the status strip, and frames the imported geometry. Save/export remains unavailable.
- Read-only smoke check of the user-supplied `octodraw.octd` (SHA-256 `a8e9fa2f2cd46e641d32466b61e12347e2c9e75b6b95f6381ccaa7626296a908`) produced 2 definitions, 3 layouts, 17 occurrences, 16 child objects, 524 effective segments, and 460 effective triangles. Edge/face counts match the supplied Selection screenshot. The source file was not changed.
- Updated the supplemental UI reference captions to match the supplied image contents; renamed the architecture-only capture because it contains no HVAC panel.

Checks: `cargo test -p meshcraft-core` (19 tests); `cargo test -p meshcraft-desktop` (8 tests); a temporary out-of-repository Rust check imported the user scene and computed its effective counts. `python3 docs/rewrite/scripts/verify_plan.py` passes.

Limits: gzip, rootGroup and flat-history shapes are rejected; full per-DTO sparse defaults, nested unknown-field retention, undo history, schema-17 export, camera/settings restoration, and all-60-fixture comparison remain unimplemented. The importer currently lives in `crates/meshcraft-core/src/legacy.rs` pending the T46/T03 IO boundary decision.
