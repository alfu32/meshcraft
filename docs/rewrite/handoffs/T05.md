# T05 handoff

Status: in progress; T03 and T46 are complete.

The IO layer reads JSON/gzip projects, normalizes current prototype/instance, prototype-only, rootGroup, and flat geometry shapes, validates the candidate, and retains opaque undo entries separately from model data. The core exports schema-17 prototype/instance snapshots through `legacy::export_current_value`; `project::write_project` adds optional opaque history and applies the legacy 10 MiB compression threshold.

Export expands shared layouts and preserves occurrence IDs, frames, geometry, hotspot edits, model settings, and unknown DTO payloads. Synthetic roots support empty and multi-root documents; generated ID conflicts are remapped deterministically. Typed domain values now map to schema-17 voxel, architecture, HVAC, and hotspot fields, with shape checks and explicit errors for unknown keys. Async Save/Save As preserve imported history on clean saves; dirty saves encode the bounded native transaction timeline and discard stale imported snapshots.

Persisted defaults now cover sparse prototype names, glue/external-reference fields, segment and face geometry DTOs in prototypes and instance overrides, alongside voxel, architecture, HVAC, hotspot, dimension, text, and instance annotation DTOs; nested references and unknown fields are retained. Blank names now match Kotlin's load-time fallback (`Root` for the existing root prototype, `Object` for new prototypes and legacy groups). Keep them distinct from panel defaults: frame creation shows glazing enabled but persisted omission is false; Vector Text shows `TEXT`/1.0 while its DTO defaults are empty/0.1.

Sparse DTO defaults now merge recursively into present nested vectors/colors, without replacing explicitly authored components. Polyline, contour, and walking-path vector items receive their `Vec3Dto` defaults; prototype vertex records also receive missing integer coordinates while retaining unknown fields.

Definition domain arrays now receive aligned in-memory semantic IDs during import, including dimensions and text whose legacy DTOs do not persist IDs. The sidecar is validated and is not emitted into schema-17 payloads.

Checks: `cargo test --workspace --quiet` passes (206 core, 193 desktop, 15 IO, 5 CLI), including sparse prototype-name and geometry defaults. `cargo run -p meshcraft-io --example probe_fixtures -- --roundtrip` passes all 60 fixtures with canonical schema-17 payload comparison (eight-ULP float tolerance; exact structure and nonnumeric values), including the 1,281-placement `docs/tutorial/000_interface.octd` and the local `octodraw.octd`. It reports the documented empty-root zero-basis repair for `examples/xref_chair.octd`. Formatting, all-target Clippy, desktop WASM check, plan validation, and `git diff --check` pass. Native dialogs and Kotlin reopen remain untested.

Changed paths: `crates/meshcraft-core/src/{document.rs,legacy.rs,transactions/mod.rs}`, `crates/meshcraft-io/src/{legacy.rs,project.rs}`, `crates/meshcraft-io/examples/probe_fixtures.rs`, `apps/desktop/src/app.rs`, `DASHBOARD.md`, and this handoff.

Still open: explicit defaults for all 32 DTOs, Kotlin reopen fixture comparisons, typed domain DTO construction, preserving imported snapshots alongside edited native history, and C03/C04/C06/C32 acceptance. Keep T05 in progress.
