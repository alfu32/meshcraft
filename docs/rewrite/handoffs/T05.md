# T05 handoff

Status: in progress; T03 and T46 are complete.

The IO layer reads JSON/gzip projects, normalizes current prototype/instance, prototype-only, rootGroup, and flat geometry shapes, validates the candidate, and retains opaque undo entries separately from model data. The core exports schema-17 prototype/instance snapshots through `legacy::export_current_value`; `project::write_project` adds optional opaque history and applies the legacy 10 MiB compression threshold.

Export expands shared layouts, preserves occurrence IDs, nonidentity frames, geometry, face colors, hotspot positions, differing geometry overrides, model settings, and unknown DTO payloads. Synthetic roots support empty and multi-root documents. Conflicting generated IDs are remapped deterministically. Typed `domain_data` without a schema-17 adapter fails explicitly instead of being dropped. The desktop now exposes asynchronous Save/Save As; dirty saves omit stale imported undo snapshots and report that loss, while clean saves preserve them.

Checks: `cargo test --workspace` passes (68 core, 40 desktop, 12 IO). The fixture probe passed schema-17 write/reopen for 12 small fixtures and the 1,281-placement `docs/tutorial/000_interface.octd`. A full 60-fixture read-only run passed previously; full-suite write/reopen remains outstanding. Native file dialogs and Kotlin reopen were not manually exercised.

Changed paths: `crates/meshcraft-core/src/{document.rs,legacy.rs}`, `crates/meshcraft-io/src/{legacy.rs,project.rs}`, `crates/meshcraft-io/examples/probe_fixtures.rs`, and `apps/desktop/src/app.rs`.

Still open: explicit defaults for all 32 DTOs, complete Kotlin/Rust fixture comparisons, typed domain DTO conversion, durable edited-history export, and C03/C04/C06/C32 acceptance. Keep T05 in progress.
