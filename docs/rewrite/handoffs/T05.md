# T05 handoff

Status: in progress; T03 and T46 are complete.

The IO layer reads JSON/gzip projects, normalizes current prototype/instance, prototype-only, rootGroup, and flat geometry shapes, validates the candidate, and retains opaque undo entries separately from model data. The core exports schema-17 prototype/instance snapshots through `legacy::export_current_value`; `project::write_project` adds optional opaque history and applies the legacy 10 MiB compression threshold.

Export expands shared layouts and preserves occurrence IDs, frames, geometry, hotspot edits, model settings, and unknown DTO payloads. Synthetic roots support empty and multi-root documents; generated ID conflicts are remapped deterministically. Typed domain values now map to schema-17 voxel, architecture, HVAC, and hotspot fields, with shape checks and explicit errors for unknown keys. Async Save/Save As omit stale imported history on dirty saves and preserve it on clean saves.

Persisted defaults now cover sparse voxel, architecture, HVAC, hotspot, dimension, text, and instance annotation DTOs, retaining nested references and unknown fields. Keep them distinct from panel defaults: frame creation shows glazing enabled but persisted omission is false; Vector Text shows `TEXT`/1.0 while its DTO defaults are empty/0.1.

Sparse DTO defaults now merge recursively into present nested vectors/colors, without replacing explicitly authored components. Polyline, contour, and walking-path vector items receive their `Vec3Dto` defaults; prototype vertex records also receive missing integer coordinates while retaining unknown fields.

Checks: `cargo test --workspace` passes (77 core, 67 desktop, 12 IO), as do formatting, workspace Clippy, desktop WASM check, plan validation, and `git diff --check`. The schema-17 probe passed all 60 fixtures, including the 1,281-placement `docs/tutorial/000_interface.octd`; one documented empty-root zero-basis repair warning occurred for `examples/xref_chair.octd`. Native dialogs and Kotlin reopen remain untested.

Changed paths: `crates/meshcraft-core/src/{document.rs,legacy.rs}`, `crates/meshcraft-io/src/{legacy.rs,project.rs}`, `crates/meshcraft-io/examples/probe_fixtures.rs`, `apps/desktop/src/app.rs`, and this handoff.

Still open: explicit defaults for all 32 DTOs, complete Kotlin/Rust fixture comparisons, typed domain DTO construction, durable edited-history export, and C03/C04/C06/C32 acceptance. Keep T05 in progress.
