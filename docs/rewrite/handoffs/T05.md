# T05 handoff

Status: in progress; T03 and T46 are complete.

`meshcraft-io` reads JSON/gzip project containers, validates the normalized model before returning it, and preserves sparse history metadata for lazy base64/gzip replay. `legacy::normalize_scene_shape` accepts current prototype/instance documents, prototype-only recovery, historical `rootGroup` trees, and flat segment/face snapshots. Malformed prototype containers return an explicit error. Unknown nested DTO and geometry-entity fields remain in opaque extension maps; segment and face extensions survive normalized geometry storage. A zero-basis root is repaired only for an effective empty root; original axes are retained and the reader returns a warning. The desktop startup status displays that warning.

The desktop Undo/Redo timeline lazily adapts supported legacy history entries. Corrupt entries remain inspectable and produce diagnostics without discarding a valid model.

Checks: `cargo fmt --all --check`, `cargo test --workspace` (60 core, 16 desktop, 10 IO), workspace Clippy with warnings denied, `cargo check -p meshcraft-desktop --lib --target wasm32-unknown-unknown`, `verify_plan.py`, and `git diff --check` pass. `cargo run -p meshcraft-io --example probe_fixtures` loaded all 60 pinned payloads read-only; 60 passed with one reported empty-root repair. Checking the desktop binary for WASM is not supported because `main.rs` uses native-only `eframe` entry points.

Changed paths: IO scene-shape normalization, reader tests and fixture probe; core geometry entity extension storage/import; startup repair warning; compatibility and T05/T17 handoffs; live reference screenshot index captions.

Still open: explicit defaults for all 32 DTO classes, the complete 60-fixture Kotlin/Rust comparison, domain-specific DTO conversion, schema-17-compatible model export, and full C03/C04/C06/C32 acceptance. The project container writer helper is not a substitute for schema-17 document export. Keep T05 in progress.
