## App change

Panels did not report their controls, so a recording could only click them at fixed
coordinates that move with scrolling. The Materials and Shader Programs panels now report
`panel/` keys in `k3d_status.workspace.controls`: the two tabs, every model and library
tile, `panel/materials/scroll` (the visible part of the tile list, measured outside the
scrolling element), program rows and panel buttons. They are forgotten as each frame
begins, so a collapsed panel or hidden tab reports nothing. Documented in
[docs/mcp.md](../../mcp.md). `verify_materials_panel.py` gained two checks for this.

## Not verified

- Narration was measured, not heard: speech rates per line and loudness are recorded
  above. The owner should listen to the "Ooh", "Hmm", "Nice" and "Wooow" lines and to
  "Look, a mirror…", which replaced a "Wow, a mirror!" clip that ran at 6 characters per
  second with a trailing sound.
- Browse's file dialog is pointed at but not opened; Xvfb has no desktop portal, so the
  path is typed.
- Only Mesa software GL. Under it each window frame takes a few tenths of a second, so
  editor typing is paced at about 0.3 s per key.
