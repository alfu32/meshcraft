## IFC property metadata — 0.27.0 (2026-10-23)

Prototype defaults and independent instance properties use the official IFC4X3_ADD2
(4.3.2.0) catalog: 3,988 PSD properties/quantities and 436 schema types. Original
release inputs are pinned with hashes and attribution, and a standard-library
generator reproduces the offline index. Property kinds include single, enumerated,
list, bounded, table, reference, complex and quantity, with unit/type/options data.

Native prototype/instance editors and MCP use the same validated, undoable model
transactions. Creation copies defaults; copy preserves snapshots. Scripts declare
`$IFC` in prototype/onCreate scope and read immutable `this.ifc`. One-shot geometry
baking retains both scopes. Project serialization keeps complete metadata.

The existing proxy exporter now writes IFC4X3_ADD2 property/quantity relationships
and imports their supported forms. Tests cover structured kinds, separate table
axis types/units, Unicode, quantities and explicit SI units. Non-document reference
graphs and unsupported explicit units fail with diagnostics; geometry proxies are
not full BIM class/model-view certification. See the [IFC guide](../../ifc-properties.md)
and [release validation](object-properties-validation.md).
