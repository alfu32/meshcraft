# T06 handoff

Status: in progress; T04 and T46 are complete.

Added `meshcraft_core::commands`: validated `CommandId`, versioned descriptors and payloads, parameter types, capabilities, mutation/tool kinds, state queries, action-tree presentation metadata, host effects, completion results, and a deterministic registration-order registry. Dispatch rejects unknown IDs, disabled context, schema mismatch, missing/extra arguments, and wrong value types before invoking the handler.

The desktop’s built-in command registrations use this registry for palette search, menus, tool icons, and Tools/Modeling button groups. It catalogs 157 commands: current Rust commands, all 74 pinned built-in tool IDs, legacy static IDs, six orthographic IDs, and 24 toolbar visibility IDs. Implemented legacy aliases dispatch to the same Rust handler; unavailable features carry `Deferred` capability and show a disabled reason. Legacy inspector commands open and scroll to the matching section. Undo/Redo and selection preconditions expose disabled reasons; active tool, profile, and visibility commands publish checked state. Tool activation is classified separately from document mutations and does not create document history.

`MeshcraftApp` exposes the same command catalog, state query, and versioned structured dispatch used by the UI. Cuboid creation accepts optional three-number dimensions and origin; array creation accepts an optional positive copy count and numeric spacing. Dispatch results report completion, diagnostics, document revision, and created occurrence paths. Palette and structured dispatch share the same registry and handlers. Camera orbit, reset and frame-document actions are registered; reset restores the default isometric view without editing the document.

File/storage/capture/job effects have typed contracts, but are not yet connected to desktop host services.

Checks: `cargo fmt --all --check`; `cargo test --workspace` (65 core, 25 desktop, 10 IO); `cargo clippy --workspace --all-targets -- -D warnings`; `cargo check -p meshcraft-desktop --lib --target wasm32-unknown-unknown`; `python3 docs/rewrite/scripts/verify_plan.py`; and `git diff --check` pass.

Changed paths: `crates/meshcraft-core/src/commands.rs`, `crates/meshcraft-core/src/lib.rs`, `apps/desktop/Cargo.toml`, `apps/desktop/src/app.rs`, `apps/desktop/src/viewport.rs`, T06 task registry and this handoff.
