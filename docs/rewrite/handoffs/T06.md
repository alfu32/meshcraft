# T06 handoff

Status: in progress; T04 and T46 are complete.

Added `meshcraft_core::commands` with validated IDs, versioned descriptors and payloads, typed parameters, state queries, capabilities, action metadata, results, and a deterministic registry. Dispatch validates command availability and payloads before running handlers.

The desktop registry drives palette search, menus, toolbars, and structured dispatch. Its 184 descriptors include all 74 built-in tool IDs, legacy static IDs, six orthographic views, 24 toolbar visibility commands, and 18 inspector toggles. Unsupported features remain marked `Deferred`.

Implemented undoable Delete Selection, session-only Clear Selection, and the legacy `edit.reset_scene_for_capture` workflow. Nested deletion copies child layouts per occurrence to preserve other instances. Capture reset clears the document and tool drafts, restores the Y-up perspective overview, and hides inspector panels. `document.snapshot` returns serialized document, selected occurrence paths, camera pose, and revision without changing history. Cuboid, array, settings, camera, and File Open/Save operations also dispatch through the registry.
