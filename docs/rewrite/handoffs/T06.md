# T06 handoff

Status: in progress; T04 and T46 are complete.

Added `meshcraft_core::commands`: validated `CommandId`, versioned descriptors and payloads, parameter types, capabilities, mutation/tool kinds, state queries, action-tree presentation metadata, host effects, completion results, and a deterministic registration-order registry. Dispatch rejects unknown IDs, disabled context, schema mismatch, missing/extra arguments, and wrong value types before invoking the handler.

The desktop’s built-in command registrations use this registry for palette search, menus, tool icons, and Tools/Modeling button groups. The current catalog contains 183 commands: current Rust commands (including T09’s file operations), all 74 pinned built-in tool IDs, legacy static IDs, six orthographic views, 24 toolbar visibility IDs, 18 inspector-section toggles, and canonical Delete and Clear Selection commands. Implemented legacy aliases dispatch to the same Rust handler; unavailable features carry `Deferred` capability and show a disabled reason. Legacy inspector commands open and scroll to the matching section. Undo/Redo and selection preconditions expose disabled reasons; active tool, profile, camera view, and visibility commands publish checked state. Tool activation is classified separately from document mutations and does not create document history.

`MeshcraftApp` exposes the same command catalog, state query, and versioned structured dispatch used by the UI. Inspector headers have generated palette toggle commands. Cuboid creation accepts optional three-number dimensions and origin; array creation accepts an optional positive copy count and numeric spacing. Model Settings edits (unit name/scale, grid size, circle segments and snap radius) dispatch through the registry and document transaction history. UI Settings controls dispatch typed preferences through the same registry without creating document history; invoking either settings command without a payload opens its inspector section. Dispatch results report completion, diagnostics, document revision, and created occurrence paths. Palette, inspector, and structured calls share handlers. Orbit, six orthographic views, reset, and frame-document actions are registered; camera changes do not edit the document.

`edit.delete_selection` is available from the Edit menu and command palette and uses the Delete key when no text field owns keyboard input. It removes non-overlapping selected occurrences across multiple parents as one undoable edit; nested group deletion installs an occurrence-local child-layout copy so other placements retain their original children. `edit.clear_selection` uses the same menu, palette, and structured-dispatch route while changing only session selection state.

File Open and Save/Save As connect the registry to native dialogs, staged worker-thread IO, progress/cancellation, safe revision-checked publication, and atomic writes. Autosave, recovery, capture, and the other storage/job effects still await their desktop services.
