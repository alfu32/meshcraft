# T06 handoff

Status: in progress; T04 and T46 are complete.

Added `meshcraft_core::commands` with validated IDs, versioned descriptors and payloads, typed parameters, state queries, capabilities, action metadata, results, and a deterministic registry. Dispatch validates command availability and payloads before running handlers.

The desktop registry drives palette search, menus, toolbars, and structured dispatch. Its 194 descriptors include all 74 built-in tool IDs, legacy static IDs, six orthographic views, 26 toolbar visibility commands for the 13 screenshot groups, and 18 inspector toggles. Per-toolbar visibility persists in UI preferences. The tool buttons use source-mapped icon aliases; the atlas parser clamps the last legacy CSV tile edge to the actual image boundary. Rendering toolbar commands match the supplied RT/GI/Stop/Save screenshot; they remain discoverable and explicitly `Deferred` until the rendering tasks implement them. Workspace reset and native Exit are registered commands shared by the palette and menus; reset preserves document state.

Implemented undoable Delete Selection, session-only Clear Selection and Set Occurrences, and the legacy `edit.reset_scene_for_capture` workflow. Nested deletion copies child layouts per occurrence to preserve other instances. Capture reset clears the document and tool drafts, restores the Y-up perspective overview, and hides inspector panels. `document.snapshot` returns serialized document, selected occurrence paths, camera pose, and revision without changing history. Cuboid, array, settings, camera, and File Open/Save operations also dispatch through the registry.

The user-confirmed modeling constraints are recorded in `spec/modeling.md` and `spec/foundation.md`: selection-first operations; nested object instances and in-place definition editing; direct construction in the active graph; planar-first construction with extrusion; distinct linear/planar/spatial and rotational/helical arrays; attached hotspot operations; and explicit two-, three-, four-point and unbounded path workflows.

Checks pass: `cargo test --workspace` (78 core, 71 desktop, 14 IO), `cargo fmt --all -- --check`, workspace Clippy with warnings denied, `cargo check -p meshcraft-desktop --lib --target wasm32-unknown-unknown`, plan validation, and `git diff --check`.

Changed paths: desktop command/presentation registry, icon atlas parsing, modeling/foundation specs, rewrite guide, dashboard, and this handoff.

`view.camera.set_pose` accepts required position/target vectors plus optional field of view and clipping planes, validates the complete pose before applying it, returns the canonical pose, and does not affect document revision/history. Regression coverage checks valid dispatch and that missing, degenerate, or invalid projection input leaves the camera unchanged.

Remaining: deterministic setup helpers beyond existing document and geometry commands, deferred handlers, host-effect completion, automation/tutorial clients, and full C18 presentation equivalence. Do not advertise deferred runtimes.
